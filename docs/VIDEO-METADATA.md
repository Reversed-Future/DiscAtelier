## 手动验收

1. 打开测试程序，在「影像」点击添加，选择「查找作品 / 粘贴链接」。
2. Bangumi 公开查询不需要令牌；试搜「千与千寻」，或粘贴 `https://bgm.tv/subject/311`。检查名称、原名、海报、简介和人员；点击「使用此作品 · 暂不保存」。
3. 使用 TMDB 前，在设置 → 影像资料填写自己的 **API Read Access Token**（不是 v3 API Key）。选择 TMDB 电影或剧集搜索，也可粘贴作品主页链接。链接按来源自动识别，不依赖当前下拉选项。令牌通过 Windows 凭据管理器保存，不写入收藏或普通配置文件。
4. 选择「识别包装」，上传／粘贴单张或多张正面、背面、腰封照片；最多 6 张。若需手机上传，电脑与安卓手机连接同一 Wi-Fi，点击「手机上传」，用手机 Chrome 扫描二维码，选择图片或拍照，预览后发送。
5. 电脑显示图片缩略图后，点击「识别包装」。需要先在设置 → 助手中配置支持图片输入的兼容模型。查看各字段的原值、识别值、图片编号和证据，只勾选确认的字段；可单独选一张图片用作实体封面。识别、选图和填写均不会保存收藏。
6. 返回表单后核对作品与实体版本：作品首映／首播日期、总集数和海报独立显示；本版发行日期、卷号、收录范围、地区、盘片和包装手动确认。未知字段留空。混合 BD/CD 等载体需逐盘设置。
7. 点击下一步填写购入，最后「加入收藏」才一次性保存。取消窗口应不增加收藏。保存后重启，检查资料仍在。
8. 对已有影像收藏进入「编辑版本」，查找作品或识别包装，点击「保存版本」。核对原购入金额、备注、载体和封面未被未选字段修改。
9. 如使用备份测试兼容性，检查音乐收藏、多专辑关联、Disc 绑定、播放历史及封面。新资料随备份／恢复一起保留。

图片只在点击识别后发送至已配置的 AI 接口；手机传图沿用现有临时局域网连接，接收一次或关闭窗口后停止。测试版不自动调用用户 AI 接口、不启动播放器、不读取实盘。

## 数据与边界

- 新的内部契约：`VideoMetadata` 分为 `work` 与 `physical`。
- 作品快照保存于 `video_work_metadata`，关联 `works.id`；实体扩展保存于 `video_edition_details`，关联 `editions.id`。现有标题、条码、品番、盘片、封面和购入结构保留。
- 当前每份实体关联一个作品来源条目；不将作品条目当成精确实体发行版本。作品封面可在表单中明确选用并确认保存，不自动替换原封面。
- 新增与编辑均使用 SQLite 事务、请求回执和版本冲突检查；不会先保存收藏再单独写入作品资料。
- 包装识别仅输出严格字段白名单、可见证据与图片序号；没有收藏写入工具。需要用户勾选填写，再最终保存。
- 搜索不接受任意远程接口；链接只解析 TMDB / Bangumi 作品编号，实际请求固定官方 API。限时、限长读取，错误不回显令牌或上游响应正文。
- 海报读取仅允许 TMDB 与 Bangumi 的官方图片主机；文字快照可离线读取；搜索海报与首次获取封面需要网络，保存后的封面可离线显示。
- 旧 Discogs 影像导入仍可从添加窗口进入；导入后可在编辑版本中补充影像作品资料。
