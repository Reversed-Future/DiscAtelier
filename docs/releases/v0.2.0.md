# DiscAtelier 0.2.0

- 设置新增可选 Windows 媒体控制（SMTC），支持系统播放、暂停、停止、上一首／下一首及进度控制；默认关闭，开启后保存生效。
- 网易云歌词接入完整播放页，可在曲目与歌词之间切换，随播放进度滚动，显示返回的译文，点击时间轴歌词跳转。本地音乐和 CD 通过已保存的歌曲及 Disc 关联获取歌词。
- 网易云音乐也可从右下角播放列表进入完整播放页；取得音源后自动切换正在播放的本地音乐，查询失败时保留原播放。
- 统一网易云、本地音乐和 CD 播放布局，移除顶部来源提示，调整标题与标签间距，光盘与内容区、上一首按钮对齐。
- 网易云播放弹窗补齐音量调节；SMTC 设置采用紧凑方形动效开关。

保留已有收藏、关联、设置和备份。本版不新增数据库迁移，沿用应用内签名更新。
