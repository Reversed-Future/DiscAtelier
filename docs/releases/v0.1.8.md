# DiscAtelier 0.1.8

- 修复升级前备份依赖收藏库版本的问题：即使数据库 schema 高于应用支持版本，也可独立创建 SQLite 一致性快照后更新，包含 WAL 中的已提交数据。不会迁移或修改源库；备份和完整性检查失败仍停止安装。
- 保留更新签名、版本绑定、播放状态检查和写入锁。升级、迁移和手动备份不会自动清理，设置中新增说明。
- 手动添加音乐收藏可直接搜索网易云或粘贴专辑／歌曲分享链接，读取名称、作者、简介、完整曲目和封面，无需 Discogs 数据。
- 实体载体、版本说明、条码、品番和购入信息继续由用户填写。手动封面不会被自动替换，可使用「使用网易云封面」按钮明确替换。
- 收藏、封面及网易云资料同一事务保存，失败完整回滚，重复提交不重复入库；保存后可在资料／曲目标签查看并按账号权限播放。

Windows x64，沿用原 Tauri 更新签名身份，支持 GitHub 私有仓库应用内更新。0.1.7 正常打开收藏库时，可在「设置 → 更新」升级；需已配置私有仓库 Contents 只读 Token。

若旧版已经提示「此数据库由更新版本创建」，其正在运行的旧更新逻辑仍会拦截安装，需要手动覆盖安装 0.1.8 一次，无需卸载。退出应用后先复制完整数据目录备份，再运行安装包；本次修正生效后的后续升级不再受业务 schema 版本限制。

应用标识、数据目录和 schema 8 保持不变，不清理收藏或备份。本轮不代用户执行安装器、操作窗口、个人收藏库或实物光盘；实际覆盖安装、重启、网易云读取和出声仍由用户手动验收。Tauri 更新签名与 Windows Authenticode 不同，后者尚未配置。
