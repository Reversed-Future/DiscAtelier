# DiscAtelier 0.1.28

- 曲目按实体载体和来源结构分盘，旧资料可直接按盘展示；编辑版本支持明确指定 Disc、分盘标题和盘内小标题，保留原曲号与既有关联。
- 修复同一实体中 CD 与 BD／DVD 的同名歌曲互相干扰匹配的问题。音源按 Disc 独立匹配，继续兼容大小写、标点、全半角与繁简差异；手动单曲关联优先保留。
- 内置网易云随应用在后台预启动，减少首次查询等待；退出应用时关闭，自定义服务沿用原设置。
- 每次启动自动检查更新，支持忽略此版本、稍后和查看更新；手动更新不受忽略设置影响，下载和安装仍由用户操作。
- 光驱检测与更新提示加入淡入淡出；光驱提示下移，拉开与标题、作者的距离。
- 曲目／章节页右下角保留“编辑版本”入口，与资料页保持一致。

沿用现有应用内更新签名与安装前备份流程；本版没有数据库结构迁移，保留收藏、购入资料、备份与既有播放／资料功能。
