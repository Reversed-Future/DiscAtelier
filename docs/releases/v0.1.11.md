# DiscAtelier 0.1.11

- 添加同一 Wi-Fi 下的手机连接：电脑显示临时二维码，安卓手机浏览器即可拍照识别商品条码，确认后填入 Discogs 查询框；支持手动输入条码。
- 购入表单支持手机上传购物截图／照片，最多合计 6 张；手机端提供预览、删除和发送，电脑接收后继续识别与逐项确认，不会自动保存收藏。
- 修正选图长时间无反馈的问题：增加读取进度、超时与取消，保留已成功读取的图片，避免图片准备过程一直占用选择入口。
- 修正购物截图识别结果的勾选显示和状态读取，整行可点击，展示已选字段数量；仅勾选的内容填入表单，保存后才写入收藏。

手机连接仅在主动打开时启动，使用临时令牌和有限有效期；关闭连接或退出应用后结束。请在可信的同一局域网使用，手机传输为 HTTP，不提供收藏数据库或账户凭据访问。

继续支持 GitHub 私有仓库应用内更新，沿用现有签名、收藏目录及数据库版本。安装前自动备份，备份失败不会继续安装；收藏和备份不自动清理。

自动回归、构建和更新验签记录见发布校验文档。安卓 Chrome 实机扫码、选图与实际覆盖安装仍需手动验收；本次不操作用户窗口、个人数据库或光盘。
