# DiscAtelier 0.1.10

- 助手移到右下角对话浮窗，支持流式回复、停止生成与跨页面对话，交流风格更自然，适合聊音乐和收藏。
- 助手可准备添加收藏、补全网易云资料及切换封面的具体变更，展示预览后必须点击确认才保存；过期或资料已变化的提案不能覆盖新内容。
- 助手接入播放状态、播放歌曲、暂停、继续、停止、跳转和上下曲，复用现有内置播放列表及账号音源权限。
- 购入编辑和添加收藏支持粘贴或上传 1–6 张购物截图，使用设置中的图片 AI 模型识别价格、币种、日期、店铺、链接及明确的收货状态。
- 多订单分别选择，逐项展示截图依据和修改前后值；勾选后只填写表单，保存才写入收藏。金额与币种一起应用，未选字段保留，截图不保存到收藏或备份。

继续支持 GitHub 私有仓库应用内更新，沿用原更新签名和数据目录。安装前自动备份收藏，备份失败停止安装；数据库版本不变，不自动清理收藏或备份。

助手需支持 Chat Completions／工具调用的兼容接口；购物截图需支持图片输入的模型。自动回归与模拟接口检查已通过，真实模型识别、语气和播放效果仍取决于所配置服务，识别字段请核对后保存。
