# DiscAtelier 0.1.27

- 新增自定义资料编辑：可编辑已保存的曲目、Disc、Credits、公司、专辑简介，以及影像作品、角色头像与章节资料。Credits 曲目使用折叠多选下拉，添加前后表头列位置保持一致，修复虚线框缺边。
- 收藏搜索支持已保存曲目和影像章节；支持搜索当前插入 CD 的曲目。本地视频关联统一显示章节，并可手动选择关联章节。
- 修复 DVD / BD 菜单 AI 识别请求异常及错误提示消失，显示识别阶段和计时。菜单识别依据演出日期、场馆和具体 Disc 内容自动关联，支持用户纠错；AI 判断位于光驱控制下方。
- 修复 Discogs 的 CD + BD1 + BD2 被合并显示的问题；各盘按数据源顺序同级展示，长标签换行显示。
- 修复编辑器删除嵌套曲目时误删所属整组的问题，保留其他曲目和分盘。
- 保留已有收藏管理、Discogs / 网易云 / TMDB / Bangumi、网易云登录与播放列表、CD / DVD / BD 与本地播放、助手、手机上传、模型交互、备份管理和应用内更新功能。

本次新增 Disc 关联字段，旧收藏与关联保留，数据库升级前自动备份。沿用现有应用内更新签名身份。真实光盘菜单与播放效果受盘片、驱动和运行环境影响，未逐盘复测；本版仍为 0.1 系列。
