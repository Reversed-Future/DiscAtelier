# DiscAtelier 0.1.15

- 前后编翻面：一份实体可设置前后两编，分别分配作品资料与封面。首页保持一份收藏，以叠放卡片呈现；详情翻面切换标题、简介、章节、角色和图库，保留当前标签，共用购入信息。
- 修复取消文件选择后退出编辑界面的问题，取消选图时保留编辑草稿和所在页面。
- 列表支持拖动行首手柄排序，也可按 Alt + 上下方向键调整；顺序保存到本地，重启后继续使用。
- 改用与顶部导航协调的黑白自定义窗口栏，支持拖动、双击最大化／还原、最小化和关闭。弹窗打开时仍可操作窗口，视频全屏时隐藏窗口栏。

旧收藏不会自动分编；来源关联、购入资料、收藏与备份保留。数据库从 schema 11 升至 13 前自动备份。继续支持 GitHub 私有仓库内的签名更新，安装前备份收藏。
