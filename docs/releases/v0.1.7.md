# DiscAtelier 0.1.7

- 网易云社区 API 内置于应用，按需启动，退出时关闭；支持专辑搜索分页、封面展示、分享链接读取及 Discogs 入库时关联。
- 设置加入网易云扫码登录、账号头像和退出；认证凭据保存在 Windows 凭据管理器，播放按账号实际权限获取完整音源或试听。
- 网易云播放列表收进右下角，可跨页面播放；点击单曲载入整张关联专辑，保留最近三个专辑，支持上一首／下一首、暂停、拖动、列表循环和单曲循环。
- 网易云简介与数字发行信息合并到收藏资料；补充 Discogs credits、companies、notes 和逐曲 credits，支持繁简转换等曲目匹配及手动关联。
- 网易云资料支持「用作封面」；编辑版本封面区新增「使用网易云封面」，直接读取已关联专辑，预览后随版本保存。保留上传模型及模型优先展示。
- 调整资料／曲目／购入、Disc 标签间距和设置留白，保留黑白界面与切换动效。
- 一并包含自 0.1.6 以来的音频 CD 只读播放、网易云信息补充，以及兼容 Chat Completions 的 AI 助手第一阶段。

Windows x64，包含 Tauri 更新签名并沿用现有签名身份。0.1.4–0.1.6 可在「设置 → 更新」检查并安装，需配置具有此私有仓库 Contents 读取权限的 GitHub Token；0.1.3 请手动下载安装。

收藏目录及应用标识不变。正式版 0.1.6 的 schema 6 会迁移到 schema 8，迁移前自动备份；已使用 schema 8 预览版的收藏无需再次迁移。安装前备份机制保留。回退旧版需使用迁移前备份。

没有执行安装器、操作用户窗口或实物光盘。覆盖安装、跨版本重启、真实账号音源及界面由用户手动验收。Windows Authenticode 未配置；它与已经启用的 Tauri 更新签名不同。VLC、MPV、MakeMKV 不包含在安装包中。
