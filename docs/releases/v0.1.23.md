# DiscAtelier 0.1.23

- 新增“更多 → 本地文件”和每个收藏详情的独立“本地文件”入口，可递归扫描文件夹、自动匹配音乐/影片，并逐文件填写集数或轨号。
- `S01E01`、`第 01 集`、`EP01`、开头 `01/02/03` 与 `CD03`、`Track 12` 可识别集数/轨号；没有数字前缀的 `艺人 - 歌名` 会读取专辑曲目表匹配轨号，并在轨号旁显示匹配曲目名。
- 曲目行显示本地播放三角和白色网易云按钮；章节行显示本地播放三角。取消整行 hover，只保留按钮反馈。
- 插入已关联的 CD／DVD／Blu-ray 后，每 3 秒检测光驱；底部提示是否跳转到对应收藏，确认后切换分区并滑动到该条目。标题旁光驱图标可打开光驱界面。
- 网易云按钮使用从官方 SVG 提取的白色图形。
- 本地文件关联保存在数据目录的 `local-files.json`，不进入 SQLite 备份。

本版没有数据库 schema 迁移，schema 保持 15。真实 DVD／Blu-ray 菜单、BD-J 和光盘菜单 AI 识别仍需真实样盘验收；Windows Authenticode 未配置，因此本版仍不是 1.0。
