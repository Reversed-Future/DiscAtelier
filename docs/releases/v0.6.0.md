## 字幕与光盘播放

- 播放本地视频或兼容的光盘时，可以选择原片字幕、外挂字幕或 Whisper 听译。原片字幕可按播放器样式显示，图形字幕需要先识别文字。启用双语显示后，可通过配置的翻译服务显示简体中文译文。
- 在「设置 → 视频字幕」中选择 Whisper 模型、识别语言和下载源，或导入本地模型。可在预览中调整字号、位置和背景透明度。
- 光驱页提供菜单播放和直接播放。能读取光盘标题时，同时显示标题与卷标，方便查找对应的收藏。修复蓝光播放切回窗口时重复播放一段的问题。

## 收藏与版本编辑

- 音乐和影片使用统一的添加、编辑窗口。返回上一步保留草稿，字段填写有误时会定位到对应位置。
- 影片可分别记录本编和附带的特典 BD、DVD 或 CD。选定实体碟片后，可以从光驱导入盘名、章节或曲目及时长，预览后再修改标题。
- 在「编辑音乐版本 → 管理网易云关联」中查看和更换当前关联的专辑，也可逐首修改曲目对应的网易云歌曲。编辑页封面居中，并与下方操作按钮对齐。
- 在途收藏可直接标记为已购入。日元购入记录按购入日期保存换算汇率，日后查看时仍使用该笔记录的汇率。

## 助手、设置与升级

- 助手支持查询收藏、曲目及关联音源。回复可显示封面和可打开的收藏卡片，也可查看历史会话和操作记录。
- 设置按收藏、播放、资料服务和应用分组，支持搜索设置项。
- 升级后首次启动时，若数据目录名 `DiscAtelier` 可用，会自动将原目录改名，收藏和备份随目录保留。若该名称已被占用，继续使用原目录。应用的安装位置保持不变。

Windows x64 用户可在应用的「设置 → 更新与关于」检查更新，或下载本页的安装包。
