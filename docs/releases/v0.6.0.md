0.6.0 新增视频双语字幕和实体碟片编辑。观看影片时可以选用原片字幕、载入外挂文件，或让 Whisper 听译当前音轨。整理收藏时，可以把同一套发行中的本编、特典影像和附赠 CD 分盘记录。

## 视频字幕与 AI 听译

- **原片字幕**　从播放器的字幕菜单选择语言轨，可沿用原盘样式，也可选择「使用应用字幕样式」。蓝光图形字幕需要先识别为文字，请在 Windows 中安装对应语言的文字识别组件。
- **外挂与翻译**　支持 UTF-8 编码的 SRT 和 WebVTT。已有中文字幕时可直接显示，只有外语字幕时，可勾选翻译为简体中文，同时阅读原文和译文。
- **对白听译**　在本地视频或兼容光盘上开启「AI 听译」，即可识别当前音轨。支持日语、英语、中文和自动检测。仅显示原文时，下载好模型即可离线识别。开启双语后，识别出的文字会发送到「AI 助手与翻译」中配置的服务，音频在设备上处理。
- **模型与外观**　在「设置 → 视频字幕」选择 Tiny、Base、Small、Medium、Large V3 Turbo 或 Large V3。支持从 Hugging Face、HF-Mirror 下载或导入本地模型，可查看速度与预计剩余时间，已安装的模型可卸载。字幕预览中可调整字号（14–48 px）、背景不透明度和垂直位置。

## 光驱播放与实体碟片

- 光驱页提供「菜单播放」和「直接播放」。蓝光中有可读取的盘名时，会将盘名和卷标一并显示，方便区分本编与特典并关联收藏。修复了切换到其他窗口再返回时，声音和画面可能重播一段的问题。
- 在影片版本的「实体碟片」页，可以分别记录每张 BD、DVD 或 CD 的名称和内容。网站提供的分集资料与这套实体实际收录的章节可以分别维护。
- 选定目标碟片后，点击「从光驱导入」。蓝光可勾选播放列表，预览章节数量和时长，再选择追加或替换这张盘的内容。DVD 可带入章节，CD 可带入音轨。读到的盘名、时长和编号先进入编辑器，可以改好标题再保存。当盘片只提供播放列表编号时，预览会显示该编号。

## 音乐与影片版本编辑

- 添加和编辑音乐、影片版本的窗口采用一致的布局。返回上一步时保留草稿，保存遇到字段错误时会跳到相应位置。较长的表单可沿窗口边缘滚动。
- 在「编辑音乐版本 → 管理网易云关联」可查看已关联的专辑及歌手，选中某一张即可更换。单曲关联可逐首检查和改选，返回编辑页后随版本一起保存，也可以撤销本次关联修改。
- 音乐版本封面居中，并与下方操作区对齐。影片编辑将分编卡片放在章节关联之前，角色头像在编辑页与详情页均可查看。曲目、分集和歌词的右键菜单提供对应操作，双语歌词可分别复制原文、译文或两者。

## 购入状态与历史汇率

- 在途实体收到后，可直接标记为「已购入」。
- 日元记录按购入日期保存欧洲央行公布的参考汇率。遇到休市日，采用该日期之前最近一次公布的汇率。之后查看这笔收藏时，换算金额仍按该笔购入记录计算。「今日汇率与计算器」可用于估算新的购入。

## AI 助手与设置

- 可以直接询问收藏中有哪些版本、一张碟收录了哪些曲目，或某首歌关联了哪个音源。涉及具体收藏时，回复可附封面和可打开详情的卡片。涉及更换封面时，可以对照原封面与新封面，再确认修改。
- 助手可重开历史会话，操作记录可单独查看。设置按「收藏与工具」「影音播放」「资料与服务」「应用」分组，搜索可直接定位到设置项。TMDB 和 Bangumi 的资料来源说明分别显示在各自的标签页。

## 安装与数据迁移

Windows x64 用户可在「设置 → 更新与关于 → 版本更新」检查更新，也可直接下载本版安装包。[下载 Windows x64 安装包](https://github.com/Reversed-Future/DiscAtelier/releases/download/v0.6.0/DiscAtelier_0.6.0_x64-setup.exe)

升级后首次启动时，如果同级目录名 `DiscAtelier` 可用，应用会将原数据目录 `com.reversedfuture.discatelier` 整体改名，收藏与备份一同保留。如果目标名称已被占用，应用会继续使用原目录。程序仍从原来的安装位置启动。
