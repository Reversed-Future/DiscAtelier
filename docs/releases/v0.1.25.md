# DiscAtelier 0.1.25

- 本地音乐和本地视频全部改用 VLC 播放；本地音频使用纯音频模式，不创建原生视频窗口。
- 安装包内置 MPV 0.41 运行时（`mpv/mpv.exe` 和 `d3dcompiler_43.dll`）；MPV 仅用于蓝光直读播放列表和 MakeMKV 兼容兜底，不再参与本地播放。
- 启动播放时若 VLC／MPV 或插件缺失，底部显示具体错误，不再静默失败：
  - 未检测到 VLC；
  - VLC 缺少 `libvlccore.dll` 或非空 `plugins`；
  - 未检测到 MPV 或路径无效。
- 关联歌曲列支持从专辑曲目表手动下拉改选；修改轨号会立即同步歌曲标题，改歌曲也会立即同步轨号。
- 歌名匹配优先精确匹配，`夏のせい` 不会误配到 `夏のせい (English ver.)`。
- 曲目列表序号、标题、时长的垂直中线与播放／网易云图标对齐。
- 本地文件弹窗标题和表头固定，表头取消半透明；表格填满可用高度，滚动只发生在表格内部。
- 本地文件关联、CD 式本地播放器、右下角播放列表、无需停止的直接切换、原生顶层播放器返回详情、光驱插入提示和白色网易云按钮继续保留。

本版没有数据库 schema 迁移，schema 保持 15。真实 DVD／Blu-ray 菜单、BD-J／Java 兼容性和光盘菜单 AI 识别仍需真实样盘验收；Windows Authenticode 未配置，因此本版仍不是 1.0。
