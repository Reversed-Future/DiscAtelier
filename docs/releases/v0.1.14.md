# DiscAtelier 0.1.14

- BD／DVD 接入 TMDB 和 Bangumi：按作品名搜索、粘贴链接，或上传包装图片识别；沿用手机上传入口，预览确认后保存，作品资料与实体版本分开。
- 支持关联并保留多个资料来源，仅简介切换版本；属性、章节和图库合并展示，图片标注来源。保留 Bangumi 动画角色头像及性别、生日、血型、身高等资料。
- 补齐 Bangumi 分页章节与 TMDB 各季剧集，剧情简介、配图直接显示。按集号、日期和唯一对应关系匹配，兼容旧资料和不同中文译名，保留特殊篇及多季歧义边界。
- 影像请求跟随已开启的 Windows 单服务器系统代理，改善 TMDB 连接失败；失败时保留原资料。
- BD／DVD 使用竖版封面，可选择数据源封面；原标题、译名、简介字号、设置字段、标签结束线及官网行距统一调整。

沿用现有收藏目录和更新签名。数据库升级至 schema 11，迁移前备份；已有收藏、购入记录和关联保留。更新安装前另行备份，发布清理不删除收藏或备份。

Windows x64。已配置私有仓库访问的用户可在“设置 → 更新”检查并安装；也可下载本发行安装包覆盖安装。
