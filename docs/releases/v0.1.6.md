# DiscAtelier 0.1.6

- 收藏详情改为「资料／曲目／购入」三个同级标签；曲目页以原始分盘标题作为二级标签。
- 分盘标签与曲目列表增加 16 px 间距，收藏详情与 Discogs 搜索详情同步调整。
- 曲目区域固定高度、独立滚动，切换标签保留分盘选择并复用已读取的内容；流派和风格保留在资料页。

Windows x64 安装包包含 Tauri 更新签名，沿用现有签名身份。0.1.4／0.1.5 可在「设置 → 更新」通过私有 GitHub 仓库更新，需已配置有该仓库 Contents 读取权限的 Token。0.1.3 请手动下载安装。

本版未变更收藏位置或数据库结构，继续使用 schema 6 与安装前备份机制。Windows Authenticode 尚未签名。

本次不操作用户窗口或执行安装器；实际标签布局、覆盖安装及重启后收藏核对由用户手动验收。
