# DiscAtelier 0.1.18

- 蓝光默认改用随包的 libaacs 0.12.0／libbdplus 0.2.0，由 MPV 内置 libbluray 边读边解密；默认不启动 MakeMKV 实例。
- 播放设置支持从 FindVUK 自动下载 KEYDB.cfg：日语为默认主库，英语补齐缺失条目，日语标题优先；下载过程显示连接、双文件下载、合并与写入进度条。
- 导入后显示已下载来源（日语／英语／本地导入）和更新时间；来源元数据不含密钥内容。手动导入仍受较小文件限制。
- 保留 MakeMKV 兼容兜底开关与原 libmmbd64.dll 路径，仅确认 AACS／BD+／KEYDB／AACS2 解密能力不足且开关开启时尝试；普通读盘、取盘、停止、区域不匹配和 BD-J 提示不触发。兜底前释放前一播放会话，界面显示“正在使用兼容模式”。
- 光驱信息分别报告 AACS／BD+／BD-J；区域保持“未确认”，不修改光驱区域、固件或光盘，不宣称全区或完整 BD-J 菜单。
- 设置页 Bangumi 新增 Token 获取链接、7／14／30／90／180／365 天过期时间下拉框、到期日期与剩余天数显示；到期前 7 天和启动／定时检查时提醒。Discogs 新增开发者设置页跳转。
- 封面加载显示暗灰底与自左上向右下的白色扫描光（2.8 秒一轮），图片加载后淡入并停止扫描；修复已缓存封面永久扫描的问题。

随包 libaacs／libbdplus 使用 LGPL-2.1-or-later，来源、版本、哈希和许可证见 `aacs/NOTICE` 与 `aacs/COPYING.LGPL-2.1`。本版没有数据库 schema 迁移；更新签名与数据目录不变，Windows Authenticode 未配置。
