# DiscAtelier 0.3.2

## 影片资料来源

- 编辑版本新增独立“关联”页签，统一管理 Bangumi、TMDB 和本地新建来源。
- 本地来源只需要作品标题，不再要求填写条目 ID。
- 添加收藏的“版本”页恢复“关联来源”，可以直接搜索 Bangumi／TMDB 或本地新建。

## 跨站章节关联

- 同一集在两个站点的集号和播出日期相同，且只有一个对应项时，应用会自动建立对应关系。特别篇、多季重名等无法唯一对应的章节可人工选择。
- 在「编辑版本 → 关联 → 章节关联」中选择另一站点的章节，点击「保存关联」写入当前实体版本。已手动关联的行也可解除。

## 本地视频与资料浏览

- 本地视频播放器新增播放列表、上一集与下一集，按章节号排列并高亮当前集。调整倍速、音轨或音量时，弹出菜单之外的画面继续显示。
- 角色按主角、配角和客串排列。图库图片可右键设为封面，封面获取失败时可重试。本地文件关联失败时，可从设置中的诊断日志查看详细原因。

## 收藏库升级

- 首次打开旧收藏库时，会先创建备份，再升级章节关联的存储格式。手动建立的对应关系属于当前实体版本。
