# DiscAtelier 0.3.2

- 影像编辑新增独立“关联”页，统一管理 Bangumi／TMDB／本地来源。
- 添加收藏恢复“关联来源”搜索。
- 章节关联支持自动对应和编辑版本内手动选择，保存为实体版本级 `chapterLinks`。
- 收藏详情章节页移除未关联状态和提示。
- 视频播放器浮层只挖掉覆盖区域，其余画面保持可见；本地视频增加播放列表和上一集／下一集。
- 本地文件关联诊断、角色排序、图库封面等 beta 修正一并包含。
- 数据库 schema 16 → 17 迁移前自动备份。
