# DiscAtelier 0.1.5

- 购入详情改为先展示再编辑，资料与购入的编辑入口固定在底部。
- 编辑版本及购入时保留详情和封面／模型背景，保存后回到原详情页签。
- 移除“再收一套”，设置窗口加宽。
- Discogs 曲目改用分盘标签，保留原始标题；曲目与封面顶部对齐，来源按钮移至右下角。
- 新收藏保存曲目、分盘标题、流派和风格，离线可读；旧 Discogs 收藏可点击“补全资料”。
- 详情按需读取曲目，收藏陈列列表不额外加载整库曲目。

**应用内更新：**0.1.4 用户可在“设置 → 更新”检查、下载并安装。私有仓库需要配置具有本仓库 `Contents: Read-only` 权限的 GitHub Token。0.1.3 用户需手动运行本页安装包。

应用标识和数据目录保持不变。首次打开 0.1.5 会先备份数据库，再添加保存曲目和流派的 schema 6 表；保留已有收藏、封面、模型、购入信息及播放历史。旧备份可以恢复到本版；若回退 0.1.4，需使用迁移前备份。

更新包使用原有 Tauri updater 密钥签名，签名绑定版本。Windows Authenticode 尚未配置。MPV、VLC 和 MakeMKV 不随安装包分发。

前端 21 项、Rust 63 项逻辑测试及构建检查通过。本次不运行安装器、不操作用户窗口或光盘；真实覆盖安装、重启与界面验收请手动执行。
