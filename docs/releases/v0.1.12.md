# DiscAtelier 0.1.12

- 一份实体可关联多张网易云专辑，分别保留简介、发行资料和曲目，可调整关联顺序或解除指定专辑。
- 已有 Disc 1／Disc 2 可分别绑定音源专辑；自动匹配限定在指定专辑内，独立单曲关联优先，连续播放遵循实体曲目顺序。
- 封面可选择任一已关联网易云专辑；浏览切换复用已解码封面，修复进入中央时重新挂载造成的短暂黑帧。
- 纳入单曲独立关联、六种固定装配 V3 模型兼容与每日汇率换算设置。汇率仅作参考显示，不改写购入原币种与金额。
- 沿用 GitHub 私有仓库应用内更新及版本绑定签名，安装前自动备份。首次打开旧收藏库会备份并迁移到 schema 10，已有收藏、购入记录、封面、关联及备份保留。

已经使用多专辑预览版的收藏库无需重复迁移；升级后请使用 0.1.12 或更高版本，旧版本无法读取新数据库结构。备份不会自动删除，可在“设置 → 数据”管理。

在“网易云资料”添加 PM、AM 后，进入“关联曲目”，分别为两个实体 Disc 选择专辑并保存。修改资料不会自动替换封面，需明确选择“用作封面”。

实际窗口、音源播放和覆盖安装由用户手动验收；自动检查不替代实机验收。光盘始终只读。
