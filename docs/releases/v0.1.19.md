# DiscAtelier 0.1.19

这是一个功能较多的正式版本，重点完善了光驱／光盘工作流、播放器控制、收藏搜索与购入记录。

## 光驱与光盘

- 光驱面板重新分组：返回播放固定在左侧，播放历史／刷新在右侧，关联与播放操作分开。
- 光驱标题旁新增“弹出”按钮，通过 `IOCTL_STORAGE_EJECT_MEDIA` 控制托盘；播放中禁用。
- DVD 章节可显示在进度条上并用于跳转，章节进度条与主进度条一体化。
- 音频 CD 使用 MusicBrainz Disc ID 识别，显示发行标题、艺术家和关联状态；设置中可配置 MusicBrainz API 地址。
- 光盘识别支持从 MusicBrainz 标题生成收藏候选并按识别结果关联。

## 播放器

- 控制条改为图标：左侧停止与播放／暂停，右侧菜单、音量、速度、音轨和全屏。
- 音量默认仅显示图标，悬停或键盘聚焦时弹出纵向音量条。
- DVD 章节分段进度条支持悬停实心加粗高亮和点击跳章。

## 收藏、搜索与购入

- 顶部搜索框常驻显示，音乐／影像分区切换使用缓存和预取，减少闪动。
- 影像列表大标题显示原文标题，小标题显示中文标题。
- 新增同捆购入：可搜索其他 CD／影像，批量写入相同购入日期、位置、链接、币种和状态；价格不拆分，同捆条目记为 0 元。
- 编辑版本窗口重新分组，影像分编卡片改为双列卡片，作品归属改为独立列表；设置分编后隐藏冗余全局封面。

## 界面与稳定性

- 窗口首次打开居中，最大化时详情标题、封面和详情栏扩大。
- 无模型封面支持指针立体倾斜，带小范围缓入与慢速回正。
- 封面硬阴影条改为柔和环境阴影，修复封面动画与列表对齐问题。
- 设置页的账号、集成和 KEYDB 状态增加缓存，避免未登录／未配置闪烁。
- 修复章节／角色末尾多余分隔线、详情标题截断，以及若干布局问题。

## 数据与升级

- schema 升级到 15，新增 `optical_bindings` 光驱关联表；首次打开旧库前自动创建一致性备份，再事务迁移。
- 升级后可回退需使用迁移前备份；旧版无法直接打开 schema 15 数据库。
- 沿用 Tauri 更新签名身份；Windows Authenticode 仍未配置。
- 未附带播放器、MakeMKV、个人收藏库或凭据。
