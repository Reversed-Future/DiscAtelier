# DiscAtelier 0.1.22

- 设置导航新增“音乐资料”，整合 Discogs、MusicBrainz 和网易云，内部用标签切换。
- “更新”页改名为“关于”，展示版本、作者、项目地址、技术栈和许可证；软件更新保留在关于页下方。
- Discogs 添加页支持直接输入条码、品番、关键词或发行 ID，默认自动识别类型，也可手动指定兜底。
- Discogs 工具栏重新分组：设置固定在左侧，手动录入、从网易云添加、手机扫条码在右侧。
- 新增“从网易云添加”：搜索专辑后直接进入添加表单，预填标题、作者和封面，并关联网易云专辑。
- 手机扫条码改为限时连续接收：同一条码连接可连续扫描多个条码，直到关闭窗口或连接到期；截图模式仍为一次接收。
- 点击“手动录入”改为打开叠层表单，不再关闭原 Discogs 窗口；返回后保留原搜索状态。
- 实验性“识别菜单”：静默启动 DVD／Blu-ray 菜单，截取菜单画面，交给配置的图片 AI 模型生成候选；不自动写入关联。
- 仓库转为公开，项目采用 GPL-3.0-or-later；更新检查与下载不再需要 GitHub 访问令牌。
- 安装包继续内置 VLC 3.0.22、Temurin JRE 8、libaacs 和 libbdplus，不需要另装播放器或 Java。

本版没有数据库 schema 迁移，schema 保持 15。蓝光菜单、BD-J 和光盘菜单 AI 识别仍需真实样盘验收；Windows Authenticode 仍未配置。
