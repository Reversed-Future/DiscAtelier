## 回归与兼容

149 项 JavaScript、247 项 Rust 工作区回归通过，9 项环境测试默认忽略。工作区回归运行于版本号调整前的同一功能代码；统一到用户指定的 0.2.0 后，主程序另行通过 80 项测试，工作区严格 Release Clippy、源码敏感文件与版本一致性检查、TypeScript／Vite 和签名 NSIS 构建通过。

与 0.1.28 对照，121 个旧接口全部保留，新增歌词和 SMTC 的 3 个接口。运行资源映射、应用标识、更新配置及安装配置不变，无新增数据库迁移。5,607 个资源逐项核对来源与哈希，安装脚本完整包含，正式主程序不含隔离预览标记。

实际 React 组件以独立示例资料验证：三种来源、曲目／歌词两种标签、1440×960 和 960×680 两种窗口共 12 项布局组合通过；光盘与上一首按钮左边缘误差小于 1px，光盘保持圆形，底部控制条无重叠。网易云弹窗音量 0／100 指令通过。此前的 SMTC 模拟事件、歌词定位／点击跳转、失败重试、旧请求晚到处理、方形开关键盘和拖动验证记录保留。

打包后的网易云运行组件离线启动验证通过。真实声音输出、物理媒体键及 Windows 系统面板未在本次发布流程中操作，不将模拟 IPC 验证等同于硬件验收。
