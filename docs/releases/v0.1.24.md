# DiscAtelier 0.1.24

- 本地文件关联支持总入口和收藏详情独立入口；递归扫描文件夹，按专辑曲目表匹配歌曲和轨号。
- 新增 CD 式本地音乐播放器：按专辑轨号顺序展示整张专辑；关闭后缩到右下角播放列表，可直接切歌。
- 播放器使用原生顶层窗口覆盖收藏详情；关闭后直接回到原详情，不经过首页，也不会重新播放打开动画。
- 正在播放的曲目再次点击播放按钮会直接打开播放器，不再暂停或重启。
- 上一首、下一首、播放/暂停和循环统一在同一行，循环按钮位于右侧；网易云播放列表使用相同布局。
- 本地、光驱和视频播放切换会自动替换当前会话，不需要先停止。
- 曲目行增加本地播放符号和白色网易云按钮；章节行增加本地播放符号。取消整行 hover。
- 文件夹选择去掉重复路径提示，选择文件夹和扫描并列；placeholder 使用 12px。
- 关联列表新增歌曲标题列，按专辑轨号顺序排列，未匹配文件排在末尾。
- 插入已关联光盘时底部提示是否跳转；确认后滑动到对应收藏，标题旁光驱图标可打开光驱界面。

本版没有数据库 schema 迁移，schema 保持 15。真实 DVD／Blu-ray 菜单、BD-J／Java 兼容性和光盘菜单 AI 识别仍需真实样盘验收；Windows Authenticode 未配置，因此本版仍不是 1.0。
