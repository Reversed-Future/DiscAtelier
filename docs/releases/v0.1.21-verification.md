## 内置运行时

安装包包含 VLC 3.0.22 和 Temurin JRE 8.0.504+1，资源目录为 `vlc/` 和 `jre/`，并包含 `libaacs.dll`、`libbdplus.dll`。实际 CD 播放已通过内置 VLC 运行；内置 VLC 的 `libbluray` 插件和 BD-J JAR 已随包安装。

蓝光菜单需要真实蓝光样盘验收；BD-J 还需要对应光盘的 Java 内容与 VLC/libbluray 运行时兼容。本版尚未在真实蓝光光盘上完成菜单或 BD-J 的通过结论。
