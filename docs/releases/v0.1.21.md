# DiscAtelier 0.1.21

- 安装包内置 VLC 3.0.22 x64 和 Eclipse Temurin JRE 8.0.504+1，用户不再需要单独安装 VLC 或 Java。
- 内置运行时包含 libbluray 蓝光菜单插件、BD-J JAR、libaacs.dll 和 libbdplus.dll；启动时通过进程内 `VLC_PLUGIN_PATH`、`JAVA_HOME`、`LIBAACS_PATH`、`LIBBDPLUS_PATH` 和 PATH 查找，不修改系统环境。
- 播放设置的 VLC 路径留空时自动使用安装目录 `vlc/libvlc.dll`，也可以填写自定义 VLC 路径覆盖。
- 光驱页的蓝光条目提供“菜单播放”，通过 VLC 的 `bluray:///X:/` 与 `:bluray-menu=1` 打开蓝光顶层／弹出菜单；方向键、回车和播放控制条菜单按钮可用。
- 原有“直接播放”保留为 MPV 的 `bd://mpls/...` 路径，便于绕过菜单直接播放正片。
- 蓝光菜单和 BD-J 的实际可用性仍取决于光盘、VLC/libbluray 和 Java 内容；本版没有真实蓝光样盘的菜单验收结论，不能据此宣称所有 BD-J 菜单均支持。

VLC 以 GPL/LGPL 发布，Temurin 以 GPL+Classpath Exception 发布；固定版本、归档校验值、许可证文件和源码地址见 `docs/BUNDLED-VLC.md`。本版没有数据库 schema 迁移，schema 保持 15；Windows Authenticode 仍未配置。
