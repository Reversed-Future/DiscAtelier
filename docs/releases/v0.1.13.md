# DiscAtelier 0.1.13

- 助手提示词精简，保留自然陪伴、有判断力的交流风格；区分聊天、查询和播放意图，对齐多专辑资料、Disc 分盘绑定及现有工具能力。收藏修改仍须在界面确认后保存。
- V3 模型改为直接点击部件拆装、查看和翻页，移除独立操作面板；按当前状态显示放回、返回与全部收起，保留装配约束。
- 列表模式顶部导航固定，收藏列表独立滚动，滚动条使用现有边距，不挤压内容。
- 汇率来源链接恢复灰白样式；封面禁止原生拖选，移除按下缩放效果。

沿用现有收藏数据目录和更新签名，不引入数据库迁移。更新安装前自动备份；收藏和备份不会因发布后的开发文件清理而删除。

Windows x64。已配置私有仓库访问的用户可在“设置 → 更新”检查并安装；也可从本发行下载安装包覆盖安装。
