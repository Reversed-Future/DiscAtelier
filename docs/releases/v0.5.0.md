# DiscAtelier 0.5.0

## 蓝光菜单与光驱识别

- 修复部分 AACS 蓝光启动后播放窗口未显示菜单画面，或找不到随应用安装的读取组件的问题。
- 从光驱页打开蓝光播放列表时，本版通过光盘菜单进入播放。列表仍可用来查看分段、总时长和检查播放状态。
- 「设置 → 助手」新增自动识别光盘菜单的开关，默认开启。截取菜单画面约需 12 秒，截图结束即可播放，后续识别在后台继续。关闭开关后仍可手动识别。

## 音轨语言与声道

- 音轨选择器显示语言、音频编码和声道数。遇到多条语言相同的音轨，可以区分 5.1 声道与立体声。标签相同时会显示音轨序号。
- 修复部分尚未选中的环绕声音轨被标为双声道的问题。音轨较多时采用双列布局，方便对照选择。

## 全屏操作与进度

- 全屏时按空格暂停会显示控制条。在控制条已收起时按空格恢复播放，画面保持全屏。修正了菜单方向键、回车、Esc 和全屏快捷键的焦点处理。
- 插入光盘后，主界面播放列表旁会出现光驱按钮。播放中可用它回到视频，从光驱页进入播放器后，关闭时会回到光驱页。
- 修复进度条在更新播放位置时反复加速、停顿的问题。
