# DiscAtelier 0.5.0

本版集中修复蓝光菜单播放与光驱交互，并改进播放器进度、音轨和全屏操作。

## 蓝光菜单与 AACS

- 修复 VLC 的 libbluray 读不到 `LIBAACS_PATH` 的问题：同时向 ucrtbase 与 msvcrt 发布原生环境，并去掉 `\\?\` 资源路径前缀。
- 修复蓝光菜单播放从隐藏的不可见视频窗口启动的问题；AACS 加密盘可以正常进入菜单。
- 具体 `.mpls` 请求统一改走光盘菜单，不再触发 MPV 内置视频窗口的异常退出；播放列表下拉框保留用于查看分段、时长和检查播放。
- 该样盘实际为 HDMV 菜单（libbluray 报告 BD-J 0），`BDMV/JAR` 目录存在不等于 BD-J。

## 菜单识别

- 新增“设置 → 助手 → 自动识别光盘菜单”开关，默认开启。
- 明确提示识别截图期间约 12 秒占用光驱；截图完成后 VLC 会话立即释放，AI 在后台继续，此时已可开始播放。
- 关闭开关后只保留手动“识别菜单”；播放中不会自动抢占光驱。

## 音轨与分段

- 读取 libVLC 媒体轨道的语言、codec、声道数，并解析 `MPLS` STN 表取得正片全部主音轨的 PID、语言和 format。
- `00002.mpls` 实测 4 条主音轨：4352/4354 为 5.1，4353/4355 为 2.0，全部 `jpn`、`DTS-HD Master`。
- 音轨框在两条以上时使用紧凑 2×2 网格，宽约 600 px；重复标签追加“音轨 N”。
- 声道以 STN format 为准，避免 VLC 对非激活轨道报告输出 2 声道而把 5.1 显示成 2.0。

## 播放器交互

- 全屏收起控制条后，暂停状态按空格恢复播放不唤出控制条；播放状态按空格暂停并唤出控制条。
- 菜单方向键、Enter、Esc、Space、F 的焦点与采样条件修正。
- 主界面插入光盘后常驻圆形光驱按钮，位于播放列表左侧；无播放时打开光驱页，有视频会话时返回播放。
- 从光驱页启动播放，关闭播放器返回光驱页。
- 进度条改用持续的单调动画时钟，避免每次快照重建锚点造成的加速、停顿和追赶。
- 移除光驱页旧的长段说明提示。
