# DiscAtelier 0.1.4

- 设置重新设计：数据、Discogs、播放、更新四个固定分类，统一黑白、MiSans 和淡切动效。
- 菜单改为直接筛选与常用入口，收藏数量和金额集中到底部。
- 支持 GitHub 私有仓库应用内更新：检查、下载、签名验证、安装并重启。
- GitHub Token 保存在 Windows 凭据管理器，仅需本仓库 Contents 读取权限。
- 播放时禁止安装；安装前自动备份收藏，备份或验签失败则停止安装。
- “设置 → 数据”显示实际目录，并提供创建备份、恢复和打开目录入口。

**从 0.1.3 升级：**旧版没有更新模块，请关闭旧版后手动运行本页安装包一次。之后在“设置 → 更新”配置 GitHub Token，即可使用应用内更新。

应用标识、收藏目录和数据库 schema 保持不变。现有封面、模型、购入信息和播放历史沿用原库，不导入测试数据。

更新包具有 Tauri updater 签名，且签名绑定版本；Windows Authenticode 代码签名尚未配置。MPV、VLC 和 MakeMKV 仍需单独配置。

本轮未操作用户窗口、读取光盘或运行安装器；真实覆盖安装、重启和跨版本更新仍需手动验收。详见仓库 `docs/UPDATES.md`。
