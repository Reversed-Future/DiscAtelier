# DiscAtelier 0.1.16

- 修复部分光驱插入 Audio CD 后只显示卷标、没有曲目及播放入口的问题。现在使用独立只读权限读取曲目目录，显示真实曲号、时长及播放入口；读取失败会显示原因。
- 接入 VLC 的 CD 曲目资料识别，显示歌曲名、艺术家、专辑、年份／日期、流派和曲号／总曲数。资料缺失时仍可按曲号播放。
- 光驱选择框、CD 播放列表、首页播放提示和播放历史使用已识别的歌曲名；支持重新识别，缓存查询结果，换盘后核对身份，避免串用上一张光盘的资料。
- 沿用现有收藏格式、更新签名及升级前备份机制，支持应用内更新。本版没有数据库迁移。

CD 播放及资料识别使用播放设置中配置的 VLC 3。已通过实盘曲目和资料读取验证；实际声音输出及安装器交互未自动执行。
