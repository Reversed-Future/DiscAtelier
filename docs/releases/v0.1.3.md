# DiscAtelier 0.1.3

首个 Windows x64 安装版，包含最新的收藏、Discogs、模型展示和光驱界面调整。

## 已包含

- 收藏库持久化、搜索筛选、多套副本、购入信息、封面与模型、备份恢复。
- Discogs 条码／品番／关键词／发行 ID 查询，版本详情、封面下载、入库及多盘曲目分页。
- AtelierPublisher v2 模型导入，原陈列布局，取出后按需加载模型和淡切。
- 固定高度弹窗、自定义日历、详情页签稳定布局、载体去重。
- 光驱弹窗加宽，修复“播放历史”“刷新”顶部被裁切。
- 内置播放、暂停／拖动／音轨切换、播放历史、全屏控件自动收起；DVD 原盘菜单已接入，实盘验收仍待完成。

## 安装与依赖

1. 下载本页的 `-setup.exe`，关闭正在运行的 DiscAtelier 后手动安装。
2. 安装到当前 Windows 用户。缺少 WebView2 时安装程序会联网下载。
3. 首次使用 Discogs 搜索，在“设置 → Discogs”填写个人 Token；令牌保存在 Windows 凭据管理器。
4. 播放设置中配置 MPV、VLC；需要时配置 MakeMKV。安装包不包含这些播放器、商业授权或光盘内容。

原有日常收藏目录和应用标识不变；隔离测试库不会自动迁入日常库。

## 已知边界

- 本次安装包没有 Windows Authenticode 代码签名。
- 应用内自更新尚未启用；当前通过 GitHub Release 手动下载安装。未生成可用的更新清单或更新签名。
- DVD 实盘菜单、跨区域 BD 兼容性及干净机器安装／覆盖升级需专项手动验收，不宣称已全部通过。
- 光盘操作保持只读。没有光盘写入、擦除或区域固件修改功能。
- 本次没有运行安装器或操作用户桌面。

GitHub 仓库为私有，需要登录有访问权限的账号下载。资产附带 `SHA256SUMS.txt`。
