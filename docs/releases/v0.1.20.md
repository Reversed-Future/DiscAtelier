# DiscAtelier 0.1.20

- 收藏详情和首页当前标题右上角显示发光光盘标记；播放中增强辉光并缓慢呼吸，悬停可查看光驱名。详情来源栏不再显示“在光驱中 · 光驱名”文字。
- 光驱面板增加识别缓存：光驱列表、关联状态、候选、MusicBrainz 结果、CD 曲目资料和检查状态在重新打开时立即可用；后台刷新逐项比较，只有实际变化才更新，查询失败保留旧内容。
- CD 播放器上一首／下一首移入底部控制条，按停止、上一首、播放／暂停、下一首排列；首尾曲目自动禁用对应按钮。
- CD 光盘面优先显示已关联收藏封面，保留中心孔与辉光；无封面时回退银色光盘。封面加载恢复扫描动画和淡入。
- CD 与网易云播放器控制条右下角新增音量控制，浮层紧贴图标并带悬停桥，百分比数字位于滑条上方；视频播放器全屏仍固定最右。
- CD 播放器主体和曲目列表纵向居中；曲目容器按实际行高收口，可视区最后一行完整显示，不从文字中间截断。
- 播放进度改为连续时钟，带播放／暂停速率缓入缓出和误差回拉，不再整秒或 0.1 秒跳动。
- 播放器淡入／淡出统一为 220ms 对称缓动；CD 从光驱界面直接进入，不再出现先关闭光驱界面再播放的闪屏。退出时按相同 220ms 淡出。
- 首页和 CD 封面在缓存或预加载命中时仍保留至少 260ms 扫描层，再以 280ms 淡入图片。
- 修复暂停时曲目按钮短暂禁用导致列表整体变暗闪烁的问题。

本版没有数据库 schema 迁移，schema 保持 15。更新签名与数据目录不变；Windows Authenticode 仍未配置。
