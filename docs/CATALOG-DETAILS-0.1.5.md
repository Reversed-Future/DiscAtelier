## 数据与兼容

新增内部 `EditionContent` 契约及 schema 6 的 `edition_content` 表：保存流派、风格、原始曲目编号、标题、时长和嵌套曲目。入库时和收藏事务一同提交，详情按需读取；整库列表不携带曲目，不增加陈列列表的传输量。

`genres`、`styles`、`CD-1`、`DVD-1` 等外部字段与编号已核对公开发行 14262376 的实际响应（15 首 CD、14 首 DVD）。保留 DVD 原演出标题。没有明确盘号的资料不按曲目数量猜测分盘。

旧收藏缺失的内容可在资料页点击“补全资料”：根据已保存的来源 ID 读取，入库前再次核对来源，仅补缺失的内容，不更新本地标题、载体、封面、模型或任何购入字段。成功后离线可读。

首次使用此版会在现有 `backups` 下自动保存迁移前数据库，再添加表；现有收藏记录保持。旧备份可由本版恢复。schema 6 数据库需本版或后续兼容版本打开，不能直接交给 0.1.4；如回退，应使用迁移前备份。

## 手动验收

1. 打开收藏，切换资料／购入，确认标题、页签和底部编辑入口固定。购入先显示已保存值。
2. 分别编辑版本和购入，测试保存、关闭及 Esc。背景应始终是详情，退出编辑后保留页签；修改状态后也不回主页。
3. 旧 Discogs 收藏点“补全资料”，检查流派、风格和分盘曲目；关闭再打开确认保存。
4. 搜索发行 ID `14262376`，确认两个分盘标签、完整原标题的悬停文本、15／14 首曲目；第一条与封面顶部对齐。右侧滚动不带动封面及外框。
5. 检查右下角灰色来源按钮和确认按钮；打开设置确认宽度。使用日常窗口大小和缩放即可。
