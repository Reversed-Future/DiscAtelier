# 模型导入性能对照（2026-10-20）

后续首帧优化及系统文件选择验收见 [模型显示性能](MODEL-DISPLAY-PERFORMANCE.md)。本文保留导入阶段的历史测量和当时的验收状态。

本次完成 Rust 直接读取模型、不可变快照提交及分段计时。日常启动入口优先使用普通 Release；下表保留 Debug 与 Release 的同构建对照，避免把编译优化全部归因于导入改动。

## 方法

- 同一份现有《24时》模型，33,806,212 字节（约 32.24 MiB）；29 张内置图片、约 6950 万像素。每次保存后验证模型 SHA-256 一致。
- 每组 3 次，每次使用全新数据库、WebView 目录及进程；先建立无模型版本，再从编辑版本导入一次。没有重复入库命中已有资产。
- 前后程序均从 D 盘运行，数据库均在 F 盘；文件来自同一位置。没有人为清空 OS 文件缓存；正式计时期间没有同时编译或运行另一个原生测试。
- 当前桌面有其他应用负载，未控制 CPU/GPU 频率和负载；这是本机操作耗时对照，不是空闲机器基准或统计显著性结论。总耗时区间有重叠，百分比仅描述这三次的中位数。
- 自动测试替代人工选择文件的时间；之后完整执行 Rust 读取、两层校验、事务保存。正式 Release 不包含测试选择分支。

## 用户操作耗时

单位：秒，中位数。准备结束表示文件已选中并通过两层校验；保存结束表示编辑弹窗关闭。各列分别取中位数，不应横向相加。

| 构建 | 改动 | 选文件后准备 | 点击保存后等待 | 导入总计 | 总计范围 |
| --- | --- | ---: | ---: | ---: | --- |
| Debug | 优化前 | 2.51 | 17.31 | 19.83 | 14.48–21.98 |
| Debug | 优化后 | 15.52 | 1.93 | 17.44 | 16.34–17.95 |
| Release | 优化前 | 2.53 | 7.43 | 9.96 | 6.65–10.94 |
| Release | 优化后 | 6.76 | 1.90 | 8.65 | 8.22–8.66 |

Debug 总导入中位数减少 12.0%；保存阶段减少 88.9%。

Release 总导入中位数减少 13.1%；保存阶段减少 74.4%。

校验从保存阶段前移到选择文件之后，所以准备阶段变长。这里没有省略校验，也没有把校验前移算作总耗时减少。由旧 Debug 改为优化后的 Release，总导入中位数从 19.83 秒变为 8.65 秒，其中包含编译配置与代码路径两项变化。

## 模型显示与画质
