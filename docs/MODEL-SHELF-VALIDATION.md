# 竖放陈列与模型取放验收

日期：2026-10-20。范围：现有 AtelierPublisher v2 模型兼容、竖放陈列、取出／放回的连续衔接。保持 0.1.3 开发版编号，尚未发布安装包。

后续外观调整：用户要求恢复原来的中央放大、两侧逐层后退布局。本报告中的横向架面和侧向竖放外观已被替换；同画布连续取放和模型兼容实现保留，最新状态见 ROADMAP 的“陈列风格恢复”。

## 实现

- 当前收藏使用完整 3D 模型，相邻收藏使用包内预览；无模型使用封面或默认盒体。影像与音乐保持独立分区。
- 正面竖向陈列、侧向相邻项、固定架面与静态阴影；尺寸随窗口调整。未增加首页按钮或提示文字。
- 取出／放回移动同一个 React portal 和 WebGL 画布，已加载模型不重复读取、解析或挂载。取出 280 ms、放回 260 ms；中途返回从实时位置反向衔接。
- 已拆开的模型先按作者定义的收纳路径复原，再回到架上；检视时旋转过的视角恢复为陈列视角。减少动态模式直接完成。
- 修复弹窗先关闭造成的一帧零尺寸画布；共享物体归位与弹窗卸载在同一次 React 更新中完成。
- 修复 CSS 移动缩放影响绘制缓冲区的问题：使用布局宽高，并在换位置时同步更新。详情不沿用缩小后的画布分辨率。
- 上下文丢失后恢复封面，切换检视状态可重新加载。

## 画质

保留原始贴图、材质、各向异性、抗锯齿、灯光、环境图、色调映射、2048 阴影图及原有最高 2 倍设备像素比。原模型动作轨迹、时长和阅读取景不变。总览方向作竖向陈列调整，复原后额外回到原陈列视角。

最大模型《把他的蜡笔拿走！》含 176,601,152 个贴图及预览像素。将总像素预算从 128 × 1024² 调为 192 × 1024²，接纳原图；单图 8192 边长、编码 16 MiB、50 MiB 包大小和完整校验保留。Rust 单元测试覆盖预算边界。

## 桌面检查

`verify-shelf.mjs` 检查架面、同一画布身份、挂载计数不增加、四次开启动效中反向返回、逐帧始终只有一个非零尺寸画布、详情绘制分辨率、减少动态模式、影像默认盒体和最小窗口 200% 无页面溢出。

`verify-models.mjs` 的 9 组检查覆盖上传／更换／移除、拆装、键盘旋转缩放、备份恢复与重启、损坏输入拒绝、大模型、快速取放、显卡上下文丢失和 200% 编辑。

`verify-model-loading.mjs` 的 6 组检查覆盖封面淡入、加载取消、快速切换、未显示画布释放、减少动态和只读协议拒绝。

验收使用隔离收藏库，不写入用户的日常收藏数据。当前测试产物保存于 D 盘；以前报告中的 F 盘记录是此前阶段的证据。
