# 网易云播放列表与封面预览

2026-10-21，本地预览，未发布安装包；收藏库仍为 schema 8。

## 手动测试

完全退出旧版，打开 `E:\ToolsForMyself\DiscAtelier\target\release\DiscAtelier-music-queue-preview.exe`，保留同目录的 `netease-runtime`。

1. 设置 → 网易云：服务说明下面不再预留固定空块；账号区显示「账号」标题、头像、昵称及退出。头像缺失或加载失败显示固定尺寸的人像占位。账号凭据仍由 Windows 凭据管理器保管。
2. 收藏详情：资料、曲目、购入标签下统一留出 16px，Disc 标签维持无高亮底纹；检查正文和标签不再贴线。
3. 点击已关联的曲目：右下角出现圆形播放列表按钮。展开后包含整张关联网易云专辑的曲目、当前歌曲进度、暂停、停止、上一首、下一首、循环模式。原详情下方的播放条已移除。
4. 收起列表，放回收藏，切换音乐／影像、打开其他收藏或设置，检查播放继续、右下角仍可操作。Esc 首先收起展开的列表，下一次才关闭所在弹窗；关闭列表不停止播放。
5. 在列表循环下把最后一首拖到末尾，确认回到第一首；单曲循环下确认重播同一首。手动上一首／下一首始终切歌。暂停、停止、失败不应触发自动连跳；网络请求失败应显示错误。
6. 先后播放四个已关联专辑，列表只保留最近三个专辑标签。重播旧专辑移到最前，重启后仍保留三个专辑及循环模式，不自动出声。点击历史曲目会重新读取当前收藏关联并获取音源。
7. 收藏详情 → 网易云资料 → 已保存的关联专辑 →「用作封面」。检查按钮显示「已设为封面」，详情及陈列封面更新；重新打开应用仍显示新封面。模型关联不变，有模型时仍优先展示模型。若未保存资料，先保存再设置封面。

## 实现边界

- 队列由应用根层管理，与详情、设置及列表弹窗的挂载生命周期分离。播放器仍使用 Rust / libVLC；前端依据自然结束状态推进一次，不预下载下一首。
- 最近三张专辑缓存于 WebView 的 `discatelier.music-queue.v1`，仅保存专辑／曲目元数据和循环模式；不保存音源 URL、Cookie 或账号头像。底层逐曲播放记录仍使用现有数据库历史。
- 每次播放重新核对已保存专辑；删除收藏、替换专辑或取消关联后，不直接使用历史中的旧曲目获取音源。获取失败会停留供手动重试，不无限循环请求。
- 头像字段依据内置 api-enhanced 的 `public/avatar_update.html` 与 `module/user_detail.js`：`user_detail({ uid })` 的 `body.profile.avatarUrl`。头像失败不影响账号验证；播放权限检查不额外请求头像。
- 封面依据已有 `/album` 的 `album.id`、`album.picUrl`。Rust 校验专辑与图片域名、禁重定向、限时／8 MB／8192px 及图片解码，再复用带版本检查的收藏更新事务保存封面，模型操作为 `keep`。失败保留原封面，不修改其他收藏资料。
- 弹窗和图片淡入、专辑切换淡切、按钮状态过渡支持减少动效偏好；列表固定高度，曲目区域独立滚动。没有使用 UI 自动操作、用户数据库或实物光盘进行测试。
