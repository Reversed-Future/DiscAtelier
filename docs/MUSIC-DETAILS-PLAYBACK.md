## 匹配与播放

- 只在用户已确认并保存的网易云专辑内匹配。标题严格相同且两侧唯一；双方时长可用时允许最多 2 秒差异。保留大小写、空格及版本后缀，不做模糊名称推断；DVD 编号曲目不自动关联。
- 手动「选择曲目／关联」从已保存专辑中选择，绑定原 Discogs 位置与标题。服务器再次检查原曲目唯一性和歌曲所属专辑，按版本号防止覆盖并发编辑。关联保存在补充资料，重启、备份恢复后保留；「恢复自动匹配」清除该条手动关联。
- 没有 Discogs 曲目时使用已保存的网易云曲目展示和播放。已有 Discogs 曲目时保持原始顺序和文字。
- 点击播放时才通过社区 API `/song/url/v1` 获取临时 URL，参数 `level=standard`、`unblock=false`。内置使用相同模块导出 `song_url_v1`；自定义模式使用相同 HTTP 路由。不缓存或持久化签名音频 URL。
- API 返回无链接时显示不可播放；`freeTrialInfo` 非空时标题标为「试听」。本轮没有增加网易云账号登录，服务未返回的完整音源无法播放。
- 复用现有 libVLC 后端、暂停、拖动和播放历史，在收藏详情内显示简洁控制。放回收藏后播放继续，可通过底部播放入口查看播放器；历史中的网易云条目可以重新获取链接并从头播放。
- 网络音频与光盘来源分别校验。只接受网易云音频 CDN 的 HTTPS 地址，不把 URL 交给光盘识别；当前光盘在播放时提示先停止。切换网易云曲目会结束旧会话，保留旧播放记录。
- 本轮不包含网易云队列自动下一首、歌词或账号登录。

## 手动验收

预览：`E:\ToolsForMyself\DiscAtelier\target\release\DiscAtelier-music-details-preview.exe`。旁边 `netease-runtime` 文件夹保持原位。

1. 完全退出旧程序，打开新预览。在已有网易云补充资料的收藏中确认「资料」出现简介；切换到「曲目」检查两级标签距离。
2. 点「补全资料」，确认有来源数据的发行出现 Credits、Companies、发行说明。没有这些数据的发行保持空缺。重新打开详情确认保存。
3. 在已保存网易云专辑的收藏中，播放已匹配曲目，测试暂停、继续、进度拖动、停止；缺失链接时应提示，不留假播放状态。播放需沿用设置中的 libVLC 路径。
4. 选一首未自动匹配的曲目，手动关联后播放；重启后确认关联仍在。再次保存另一张网易云专辑会重新建立补充资料，原手动关联随旧专辑清除。
5. 放回收藏确认音乐继续；打开播放历史检查曲名、已听时长和试听标记，尝试重新播放。
6. 本轮不需要插入或读取任何光盘。
