# 网易云单曲独立关联

2026-10-22，开发预览，尚未发行。本轮保留上轮 V3 模型支持。

## 使用与手动验收

1. 退出正在运行的 DiscAtelier，打开 `target/release/DiscAtelier-song-links-preview.exe`。
2. 找到有曲目资料、但未关联网易云专辑的音乐收藏，进入「网易云资料 → 关联曲目」。
3. 选择一首原曲目，粘贴网易云歌曲分享链接，点击「读取」。核对歌名、歌手和时长，再点击「关联这首歌」。读取预览不会保存，确认才写入关联。
4. 回到收藏曲目页点击这首歌，确认播放、暂停、拖动、跨页面播放、右下角列表及列表／单曲循环。音源继续使用已登录账号的实际权限。
5. 可把另一首曲目关联到其他专辑中的歌曲。两首独立关联歌曲都应进入此收藏的播放列表，不需要先保存任意网易云专辑。
6. 给收藏保存或更换网易云专辑资料，再次查看原曲目。已有独立关联应保留，收藏名称、原曲目标题、购入记录不变。
7. 在关联窗口点击「恢复自动匹配」（有关联专辑）或「解除关联」（无关联专辑），重新打开曲目页确认效果。重启程序后已保存的关联仍应保留。

目前直接读取已支持的 `music.163.com/song?id=…`、`/#/song?id=…` 和 `/song/…` 分享链接，允许附带分享文案。短链接不做未经验证的跳转解析；读取失败显示具体错误，已存关联不被覆盖。

## 数据与兼容性

- 新建 `edition_song_links` 表，逐曲关联独立于 `edition_supplements`。曲目位置与原始标题按精确值保存；只有自动匹配歌名沿用既有繁简等文字规则。
- schema 从 8 升至 9，首次打开先产生 `before-schema-8-*.sqlite3` 完整备份，再在同一事务迁移旧手动关联；备份失败不继续迁移。旧 0.1.11 和上轮 V3 预览无法直接打开升级后的库，请继续使用本轮预览；更新入口仍可使用。
- 保存使用版本号防冲突，关联写入失败回滚版本号。解除关联同时清除对应的旧格式手动覆盖，恢复自动匹配。
- 关联进入完整 SQLite 备份，恢复时校验字段和曲目标识。过时或重复的原曲目标识不会用于播放。没有改写个人收藏库、购入记录、凭据或已有备份。
- 歌曲详情字段取自本地 api-enhanced `interface.d.ts` 的 `SongDetail` 契约；直接调用已有 `songDetail` 管道，不依赖获取所属专辑。
- 原有专辑补全、封面、账号权限和流式音源获取保持现有路径。最多三个播放历史按收藏版本区分，避免多个未关联专辑的列表互相覆盖。
