## 后端

已安装 MPV 手册明确说明 DVD 菜单不受支持，`dvdnav://` 只是 `dvd://` 的旧别名，不能通过改 URL 获得菜单。

DVD 菜单采用可独立替换的 libVLC 3 后端。依据 [VideoLAN 官方接口](https://videolan.videolan.me/vlc-3.0/group__libvlc__media__player.html)：

- `libvlc_media_player_set_hwnd` 将视频放入已有原生区域。
- `libvlc_media_player_navigate` 提供确认、上下左右和弹出菜单导航。
- `libvlc_video_set_mouse_input` 控制菜单鼠标交互。
- 原盘的菜单程序负责实际章节、音轨、字幕和按钮行为；应用不重新拼造菜单。

BD 现有 MPV 后端保留。两种后端共享播放页面与类型化用例，设备识别、播放控制、原生窗口和历史持久化分别负责自己的职责。前端不暴露任意 libVLC 调用或任意媒体路径。

## 已接入的代码

1. Windows 适配器增加 DVD-Video 识别，有限读取 IFO 形成介质标记；点击前重新核对实际设备和标记。
2. 设置中增加 libVLC 路径；仅加载经过检查的本机库，不依赖用户 VLC 界面的状态，不改其配置。
3. DVD 点击播放进入原盘菜单，沿用内置画面、真正全屏和自动收起。控制区只增加“菜单”；方向键与 Enter 导航，鼠标点击原盘按钮。Esc 优先退出全屏。
4. 菜单与正片的可跳转能力按播放器报告决定；菜单页禁用拖动，标题切换后同步时长与音轨。字幕由原盘菜单选择，本轮没有额外添加字幕下拉框。
5. DVD 历史需同时保存标题编号和该标题内位置。不能只保存秒数后从任意标题续播；旧 BD 记录需兼容。
6. 后端在独立工作线程加载、停止、释放，不操作用户已经打开的 VLC。窗口关闭时先异步释放视频子窗口，再退出应用。当前不是独立进程隔离，libVLC 内部阻塞和崩溃仍需实盘验证。

模块：`crates/player-vlc` 分为 ABI、媒体对象、工作线程与会话；`playback_backend.rs` 负责后端分派；`video_input.rs` 只在本应用可见视频获得焦点时读取播放按键，释放或移出焦点即不处理，不记录键盘输入。没有全局键盘钩子。全屏继续复用原生裁剪与短时动效，视频帧不经 WebView 复制。

内部路由 `dvd-menu` 是本应用新增的固定标记，不是任意媒体路径。后端先核对只读枚举得到的 DVD、挂载点和介质 token，再构造 `dvdnav:///F:/` 这类地址。菜单根入口根据 libVLC 标题描述中的 `libvlc_title_menu` 标记选择；方向和确认使用官方导航枚举。依据：[VLC 3 DVDnav 实现](https://github.com/videolan/vlc/blob/3.0.x/modules/access/dvdnav.c)。

历史新增可空 `dvdTitle`，旧记录缺少字段时仍可读取；正片返回菜单后保留最后正片标题、位置与音轨。续播先选择实际存在的非菜单标题，再设置标题内时间；不允许只拿秒数跨标题恢复。菜单循环不计入观看时长，也不标记整盘“看完”。

运行库检查：本轮 `inspect_runtime` 已在不打开媒体的情况下验证本机 libVLC 3.0.24 的全部所用 ABI 符号及实例初始化／释放。不会操作用户 VLC，不会打开 DVD。实际菜单画面与交互仍待下面的人工验收。

自动检查：45 项相关 Rust 测试通过（application 3、optical-windows 1、player-mpv 5、player-vlc 6、storage 30）；TypeScript／Vite 构建和 workspace 全目标、全特性 Clippy `-D warnings` 通过。新增测试覆盖光驱地址限制、非菜单标题续播、菜单拖动限制、导航枚举、旧设置／历史兼容、返回菜单保留书签、标题重启持久化及损坏备份拒绝。首次运行一个新测试可执行文件曾被 Windows 暂时拒绝执行，同一构建重跑及最终完整回归均通过。

## 验收

需要实际完成：原盘菜单出现、鼠标点击、方向键与确认、进入章节、返回根菜单、音轨／字幕菜单、正片暂停与跳转、标题内续播、全屏控件收起与唤回、退出清理。先使用用户这张 DVD，然后补充多集、多角度和不同区域样盘。

光盘仅允许读取。不包含写盘、转存、刻录、弹出、区域计数修改或固件操作。没有完成以上实测前，不标为 DVD 菜单已支持；DVD 菜单可行性也不代表 BD-J 或全区 BD 已实现。

具体人工步骤见 [DVD 菜单验收](DVD-MENU-ACCEPTANCE.md)。
