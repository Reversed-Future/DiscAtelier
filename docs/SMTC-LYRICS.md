# 播放页、网易云歌词与 Windows 媒体控制

本轮功能纳入 0.2.0，数据库结构不变。

## 使用

- 设置中的播放配置新增“Windows 媒体控制 · SMTC”，默认关闭，开启并保存后生效。关闭后注销系统媒体控制；退出应用时一并释放。
- 本地音乐、CD、网易云使用相同的完整播放页布局，右侧可切换“曲目／歌词”。网易云从右下角播放列表标题旁的光盘按钮进入，返回后继续播放。
- 播放页顶部仅保留返回入口；标题与标签间隔 24px，光盘上沿与曲目／歌词内容区对齐，左边缘与上一首按钮对齐。网易云小播放弹窗补齐与本地一致的音量调节。
- SMTC 设置使用紧凑方形开关，开启或关闭后仍需点击保存；支持键盘、拖动和减少动态效果偏好。
- 网易云取得音源后自动替换正在播放的本地音乐。关联查询、音源请求失败时保留原本地播放；不要求用户先停止。光盘或视频的停止限制保持原逻辑。
- 歌词显示原文及返回的译文，随播放进度定位，点击时间轴歌词可跳转。手动浏览时暂缓自动跟随，可点“回到当前”。无歌词、未关联歌曲、请求失败分别显示对应状态，失败可重试。
- 本地音乐沿用保存的文件轨号与网易云歌曲关联；CD 使用已绑定的 Disc 范围。多盘收藏没有明确光盘绑定时不套用另一盘歌词。没有歌曲关联的本地文件不会按文件名自动搜索。

## 实现边界

原生 SMTC 通过主窗口 HWND 获取 `ISystemMediaTransportControlsInterop::GetForWindow`，在窗口线程创建、更新、移除事件处理器。系统事件只传递到主窗口，带播放会话 ID，前端忽略旧会话事件和忙碌状态事件，再调用现有播放控制入口。原生快照为状态来源；标题、艺人、专辑由当前队列补充。支持播放、暂停、停止、上一首／下一首和进度请求，未实现系统面板封面缩略图。视频按视频类型提供标题及基础控制。

参考：[Microsoft GetForWindow 文档](https://learn.microsoft.com/en-us/windows/win32/api/systemmediatransportcontrolsinterop/nf-systemmediatransportcontrolsinterop-isystemmediatransportcontrolsinterop-getforwindow)。实现方法和参数同时核对本地 Windows 0.62.2 生成绑定。

内置管道新增应用操作 `lyrics`，在 Rust 运行时和 Node runner 两层验证歌曲 ID，并调用现有 API 模块 `lyric({ id })`；自定义服务使用 `/lyric?id=…`。2026-10-26 对内置 API 4.41.1 的真实响应验证了 `lrc.lyric`、`tlyric.lyric`、`romalrc.lyric`，不推测额外标志字段。返回文本有长度和类型检查；缓存仅在前端内存保存最多 30 首，不写收藏数据库或存储音源 URL。

歌词功能拆为接口适配、LRC 解析、保存关联解析和展示组件。SMTC 原生适配与播放引擎、设置持久化分开。现有封面读取、播放队列、循环模式和收藏关联复用，未改写收藏。

## 验证

- 149 项 JavaScript 测试通过，覆盖歌词时间戳、偏移、译文、回退跳转、已存本地轨号、多盘范围和手动关联优先；Node runner 验证真实方法名及无效 ID 拒绝。
- 相关 Rust 包 104 项测试通过，8 项既有忽略项（含文档测试）。覆盖旧设置默认关闭、设置持久化不改变其他字段、内置运行时进程复用、歌词响应校验和本地音频替换策略。
- 测试中复现旧 DVD HTTP 测试偶发 Windows `WouldBlock`；仅将测试服务 accept 后的 socket 显式设回阻塞模式，重跑通过，没有改变 DVD 识别产品代码。
- 严格 Release Clippy、TypeScript／Vite 和格式检查通过。
- 无窗口 Edge 测试实际 React 组件：1440×960 和 960×680 的列表与歌词不侵入底部控制；歌词定位、点击跳转、曲目切换、无歌词、失败重试、旧请求晚到不覆盖新歌均通过。验证本地请求失败保持当前会话、网易云打开／返回／从浮窗重开、SMTC 默认关闭和开关、旧会话事件忽略、媒体暂停及上一首事件。证据：`artifacts/smtc-lyrics-ui.json`、`artifacts/smtc-lyrics-ui.png`。
- 浏览器测试使用合成资料和模拟 IPC，不等同于真实音频输出、Windows 系统面板或物理媒体键验收。以上实机行为由用户在 Release 预览中测试；未启动正式版、操作真实光盘或改动收藏、备份。

Release 预览及资源、已安装程序哈希校验记录在 `artifacts/smtc-lyrics-verification.json`。
