0.1.8 已发布；远端安装包与更新验证通过后，本次预览程序已按用户要求单独删除。请从正式发行获取安装包，详见 [发布校验](releases/v0.1.8-verification.md)。

## 升级不再依赖收藏库版本

原先安装前调用 `LibraryService.backup()`；当预览版已升级数据库、旧正式版无法打开它时，更新也会被同一个错误阻断。

现在更新流程在原有光驱操作锁、播放状态检查、签名验证和收藏写入锁内，独立调用 `backup_for_update()`。它以 SQLite 只读连接打开源库，用 SQLite Backup API 获取一致性快照，包含尚在 WAL 中的已提交数据，不调用迁移、不检查业务 schema 版本。备份完整性检查、关闭和落盘成功后才发布为 `.sqlite3`，然后启动安装器；失败则停止安装。

备份失败遗留的 `.partial` 不出现在可恢复备份列表中。现有手动备份、迁移前备份和升级前备份均不自动清理；设置页已写明保留规则。源库不存在时不创建空数据库，也不创建空备份。

较新数据库仍不可由旧应用编辑，数据库读取保护保留；仅解除它与升级入口的耦合。已经发布的 0.1.6／0.1.7 安装器不能反向修补正在运行的旧版更新代码，首次切换到包含本修正的程序仍需手动覆盖安装或打开新预览程序。

## 手动添加从网易云读取

「添加收藏 → 手动录入 → 版本」的音乐分区新增「网易云资料 → 读取资料」，支持专辑搜索和已支持的专辑／歌曲分享链接。

- 选择资料后填入名称和作者；封面为空时自动读取封面，更换所选专辑时更新自动读取的封面。手动选取或移除的封面不会被自动覆盖，仍可点「使用网易云封面」替换。
- 简介、数字发行信息和完整曲目保存在网易云资料中，入库后复用详情资料、曲目页和播放列表功能。
- 保留填写的实体版本说明、载体、条码、品番和购入信息，不用数字专辑信息猜测实体发行。没有 Discogs 数据也可直接入库，不伪造 Discogs 来源。
- 新的 `netease_create_copy` 仅接受后端已读取并缓存的专辑 ID；不会信任前端传来的任意资料内容。预览过期时需重新读取。
- 封面、收藏及网易云资料同一事务保存；任何写入失败整体回滚，同一请求重试不重复入库。关闭表单不会保存草稿。

## 验证和手动步骤

新增隔离测试覆盖较新 schema、WAL 数据、原库不变、备份输出失败、损坏文件、源库不存在、事务回滚、重复提交、备份恢复以及拒绝修改已有版本。未访问实际收藏数据库或光盘，未操作窗口。

51 项前端测试、112 项 Rust 测试、严格 Clippy、TypeScript／Vite 和 Tauri Release 预览构建通过。预览程序：`E:\ToolsForMyself\DiscAtelier\target\release\DiscAtelier-update-music-preview.exe`，与本次构建主程序哈希一致；需保留同目录共享资源。未启动程序、制作安装包或更新 GitHub 发行资产。

手动验收：

1. 添加音乐收藏，选择手动录入，在网易云资料中粘贴专辑链接或搜索，确认名称、作者和封面，再填写实体载体与购入信息后保存。
2. 打开详情，检查简介、数字发行信息与曲目；点击曲目检查按账号权限播放。
3. 新建另一份草稿，先选本地封面再读取网易云资料，确认本地封面保留；点击「使用网易云封面」才替换。关闭草稿确认没有新增收藏。
4. 设置 → 数据查看备份保留说明。请勿为测试修改真实数据库的版本；较新数据库升级已由隔离数据库测试覆盖，实际安装链路需在下一发行时验证。
