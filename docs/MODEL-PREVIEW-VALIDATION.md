# 正视角与预览验收

**历史记录**：下面记录的是用户改变交互要求之前的自动加载／截图缓存实验。最新实现改为点击后加载、180 ms 双向淡切、返回后释放画布，已停用展示流程中的截图缓存；新验收使用 `scripts/verify-model-on-demand.mjs`。下面的缓存性能数字不用于描述新流程。

日期：2026-10-20。范围：封面到模型的首次切换、同视角缓存、连续取放；只使用隔离测试库，不修改个人收藏。

## 实现

初始陈列使用运行库新增内部选项 `overview: true`，沿世界 +Y 轴观察模型正面，屏幕上方为世界 -Z。与运行库已有根节点旋转一致。投影占画布的 80%，对应现有 125% 模型容器和内缩 10% 的封面区域。相机对准物体包围盒中心，不修改模型资源或贴图。单件检视仍使用已有斜视构图；全部收起恢复正视陈列。

预览缓存版本为 `overview-2`。当前选中项完成首帧后，等待至少 320 ms 并进入空闲回调，复用原画布捕获无损 PNG，不创建第二个 WebGL 场景。内存保存至多 8 份／16 MiB 的 PNG Blob，IndexedDB 保存至多 24 份／32 MiB；这些限制针对压缩图片，不代表总 GPU 或进程内存上限。缓存读取失败不影响模型，缓存不属于备份中的收藏资产。

原分辨率缓存足够时不重复编码；用户开始检视或切换收藏会取消待执行捕获。保留抗锯齿、原贴图尺寸、材质、环境光、色调映射、阴影及动作轨迹。修正初始视角不增加场景、贴图或持续渲染工作。

## 默认比例实测

证据目录：`D:\DiscAtelierBuilds\artifacts\model-preview-1792507713081`。

- `cold-cover.png` 和 `cold-model.png`：同一窗口、同一截图区域，首次原始封面与模型分别记录。模型正面四边平行，展示范围居中；材质光照、实体盒边及原图／贴图构图仍有差异。
- `cached-preview.png` 和 `live-model.png`：单独记录缓存与实时模型，不能代替首次切换验收。
- 预览与画布矩形均为 x=464.75、y=189.45、宽高 510.5 CSS px。
- 首次加载 1 个 WebGL 上下文、1 次 PNG 编码；缓存加载 1 个上下文、0 次编码。
- 取出放回、三次中途返回复用原画布，无额外编码；上下文丢失时保留缓存预览；关闭进程重新启动仍可读取缓存。
- 13 项单元测试通过，包含正视投影四边、80% 展示范围和原单件检视方向检查；`npm run build` 通过。

本次 Release 单次观测：模型读取／解析 1,770.0 ms，挂载 4,276.6 ms；挂载结束至少 320 ms 后才捕获。捕获总耗时 88.4 ms（包含异步编码），其中同步重绘与复制 6.8 ms。重载后缓存图约在页面 116.1 ms 时已可用。这里不把单次样本当成稳定性能承诺，也不把异步编码总耗时当成主线程阻塞时间。

此前倾斜视角版本的交错三次 Release 测量，中位数为改动前 6,771.4 ms、加入预览后 7,022.4 ms，约 +3.7%，样本波动较大；不能据此声称零开销。当前正视角更改没有增加渲染步骤，长期性能及大量收藏仍待专项验证。

## 对此前结论的更正

`model-preview-1792506837611/pixel-comparison.json` 的最大通道差 1/255，仅针对该次运行的缓存截图与同视角实时模型局部截图，不是用户提供的两张不同尺寸截图，也不是原始封面到首次模型的比较。本轮不以此数值作为首次切换完成的证据。
