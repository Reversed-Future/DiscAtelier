## 曲目分盘规则

依据 [Discogs Tracklisting 12.2.8、12.2.9、12.13](https://support.discogs.com/hc/en-us/articles/360005055373-Database-Guidelines-12-Tracklisting)：

- 识别 `1-1`、`2-1`、`CD1-01`、`DVD1-1` 等明确盘号，按来源顺序分页。
- 页面标题使用 `Disc 1. 名称`；有分段名称则使用对应名称，否则使用发行标题。
- 子曲目保留在其父曲目明确指定的碟片下；不把 `3.1` 解释成第三张碟。
- A／B 面或没有明确盘号的曲目完整保留；若同时存在编号碟片，则单独显示“曲目”页，不凭曲目数量分配到某张碟。
- 同一盘内的 Bonus 等分段不额外生成碟片。未知编号仍显示原始曲目，不丢弃。

`type_`、`sub_tracks` 的契约来自公开发行 6061 与 3416833 的实际 API 响应。应用新增的 `DiscPage`、`TrackRow` 仅为显示模型，不改变外部 JSON 字段或数据库。
