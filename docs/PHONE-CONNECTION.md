## 选图与勾选反馈修正

安卓 Chrome 用户反馈选图后无缩略图、再次点击选图和拍照无响应。原读取缺少超时与备用方式，且提示位于操作区下方；具体设备卡点尚未取得日志。本次改为文件读取、图片元素解码、必要时备用位图解码，分别设定 12／12／10 秒超时，支持取消，忽略并释放已取消操作的迟到结果。文件选择框在读取结束后重置；手机按钮上方显示第几张及处理阶段，逐张出现缩略图，某一张失败时已完成图片保留。

购物识别结果的复选框存在已确认的样式问题：全局清除了原生外观，本地没有恢复。已恢复原生勾选和焦点，并增加已选项数；仍需点击“填入所选字段”后填写表单，再普通保存。63 项脚本测试和前端构建通过；真实 Chrome 文件选择器与勾选显示待复测。

复测时退出旧预览，启动 `target/release/DiscAtelier-phone-images-fix.exe`，重新生成二维码并打开手机新页面。先选一张小截图，看上方显示的处理阶段，再测试多图。若仍失败，请保留提示原文；不要继续使用旧二维码或旧页面。

## 手动测试

1. 从“设置 → 更新”安装 0.1.11 并重启，核对设置中的版本号。仍沿用原数据位置；测试人员没有启动应用或读取你的个人库。
2. 手机和电脑连接同一可信 Wi-Fi。电脑进入“添加 → Discogs → 手机扫条码”，选择电脑的实际 Wi-Fi 地址，点击“生成连接二维码”。若有 Windows 网络提示，手动允许专用网络；程序不会代改防火墙。
3. 安卓手机扫码，在浏览器打开链接。点击“拍摄条码”，让条码水平居中、拍清整条并保留四周留白。识别支持 EAN-13、UPC-A、EAN-8，也可手动填写。核对数字并发送，电脑应自动关闭接收弹窗、切换条码搜索并填好数字；点击查询才访问 Discogs。检查以 0 开头的条码不会丢失首位。
4. 打开收藏的“购入 → 编辑”，或添加收藏的购入步骤，点击“购物截图填写 → 手机传图”。重新扫码，选择 1–6 张截图，或拍照；可移除后重新选。发送后，电脑应保留原有缩略图并添加手机图片。只有点击“识别”后才向已配置 AI 接口发图，勾选识别结果后填写表单，保存才写入收藏。
5. 试一次在手机发送前关闭电脑接收弹窗：手机应无法继续提交。重新连接后旧二维码失效。重复点击发送不会重复添加本次图片。按 Esc 应只关闭最上层手机弹窗，保留购入编辑。
6. 测试返回相册、旋转屏幕、长截图、删除已选图、错误条码、断开 Wi-Fi 后重新连接；核对移动端触控和电脑弹窗动效。真实安卓浏览器、相机对焦与 LAN 防火墙仍需这轮手动验收。

无法打开页面时，先核对手机与电脑不在相互隔离的访客网络、电脑所选地址属于 Wi-Fi 而非虚拟网卡。在电脑点“更换连接”重新选择。二维码应打开完整 HTTP 链接，含末尾的连接凭据；不支持选图的内嵌浏览器请改用安卓浏览器。

## 范围与生命周期

- 采用拍照后识别，不是摄像头实时预览扫码。普通局域网 HTTP 页面受浏览器安全上下文限制；不要求用户绕过浏览器限制或安装自签名证书。
- 连接有效期 15 分钟，桌面接收页失联 45 秒也会停止；一次接收、关闭接收窗口、换连接或退出软件后停止。手机切到相机／相册时，电脑接收窗口需保持打开。
- 只监听所选的本机私有 IPv4 地址及系统分配端口；不绑定全部网卡、不映射路由端口。页面、扫码库和样式均随软件内置，不从 CDN 加载。
- 每次连接独立随机凭据，通过二维码 URL fragment 交给手机，再放入 API 请求头；校验 Host、Origin、类型、大小、图片实际内容、数量和条码校验位。HTTP 不是加密传输，仅适合可信局域网；不要分享连接链接。
- 限制单次上传及处理并发、请求时间和内存总量。截图重新编码移除元数据；仅留在当前表单内存，不写成临时图片文件。不开放收藏查询、任意文件路径、AI 密钥或播放操作给手机。
- 连接服务无独立常驻子进程；软件未打开手机入口时不监听。关闭后会释放端口。

## 开发与验证

`npm run build` 会先构建手机页，再构建桌面前端。Rust 使用 `include_str!` 嵌入 `apps/desktop/mobile-dist`；首次直接跑 Cargo 之前，需要先执行 `npm run build:mobile -w @discatelier/desktop`。

新模块：`src/mobile` 负责桌面接收弹窗和条码校验，`mobile` 负责手机页，`src-tauri/src/mobile_bridge` 分离会话、HTTP 和回归测试。明确的内部协议为 `mobile_addresses`、`mobile_start`、`mobile_poll`、`mobile_stop` 以及 `/api/session`、`/api/submit`。

自动测试使用回环地址和合成条码／图片，不访问实际手机、光盘、个人收藏和真实服务凭据。检查条码图片解码、前导零、校验位、Host／Origin／凭据、错误类型、图片与总量限制、幂等提交、超时及取消、关闭后端口释放。实际手机拍照成功率与窗口视觉效果不以自动检查代替。
