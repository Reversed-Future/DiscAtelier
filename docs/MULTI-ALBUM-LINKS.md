# 多张网易云专辑与实体分盘关联

2026-10-22，开发预览，未发行。

一份实体版本可追加关联多张网易云数字专辑，各自保留原标题、简介、数字发行资料和完整曲目。添加关联不增加实体／载体数，不改动购入记录、Discogs 原始曲目、实体封面或独立单曲关联。重新保存相同专辑 ID 更新原关联，不增加重复记录。

## 使用与手动验收

1. 完全退出旧 DiscAtelier，运行同目录中的 `DiscAtelier-multi-albums-preview.exe`；保留旁边的 `netease-runtime` 资源目录。
2. 打开《24时》详情 → 网易云资料，保留已有专辑，用“添加专辑”搜索或粘贴另一张专辑的分享链接，预览后选择“添加关联专辑”。不要创建第二份实体收藏。
3. 打开“关联曲目”，切到现有 Disc 1，选择对应的 PM 或 AM 专辑，点击“保存分盘关联”；对 Disc 2 重复此操作，选择另一张专辑。用户已确认《24时》目前有两个 Disc 标签，沿用现有分盘，无需拆分或重建曲目。
4. 检查每盘匹配结果。分盘绑定后只在指定专辑内自动匹配；繁简体和标点比较规则保留。手动指定的独立单曲优先，无法明确匹配的条目仍可点击进入单曲关联。
5. 资料页的网易云区域按专辑标签切换简介；网易云资料窗口可分别查看各张数字专辑的完整曲目。“前移／后移”调整数字资料标签顺序；有实体曲目时，播放顺序始终由实体原曲目决定。
6. 点击 Disc 1 最后一首已匹配歌曲，测试下一首及自然结束后进入 Disc 2；到别的界面继续播放，确认列表循环、单曲循环和最近三份实体历史。数字专辑内不属于实体曲目的附加歌曲不会混入实体播放列表。
7. 重启确认两张简介、分盘绑定和独立单曲关联保留，收藏仍为原来的一份，价格、状态和载体数量未变。
8. 关联窗口可选择每张专辑“用作封面”；编辑版本的封面区域，多专辑时显示来源选择。普通添加关联不会自动替换封面。
9. 快速左右切换收藏（包括曾经出现黑帧的 TOTEM），再打开详情并放回，观察封面是否仍出现黑帧。该视觉问题须由用户在实际窗口验收，开发过程未控制用户窗口。

没有实体原曲目时，数字曲目按保存的关联顺序展示和播放；数字专辑不会被视为新增实体载体。有实体分盘曲目时才显示分盘绑定，沿用原有 Discogs 分盘标识，不根据 PM／AM 名称推断实体张数。

## 数据与兼容

- schema 10 新增 `edition_music_albums` 与 `edition_disc_albums`。首次升级前通过既有 SQLite 快照机制自动保存完整备份。
- 旧 `edition_supplements` 资料原字节迁入新关系表，旧资料表保留作为既有原子入库路径的桥接点；新专辑存为独立记录。
- 新内部关联合同 `LinkedMusicAlbum` 由原 `MusicSupplement` 与 `legacyPositions` 组成；原数据保留旧 fallback 曲目标识，新关联使用带专辑 ID 的内部标识，界面只显示普通曲号。调整专辑顺序不会改变已保存的单曲身份。
- 分盘键直接来自已支持的 Discogs 曲号形式，单独保存所选数字专辑 ID；保存带版本检查，移除某专辑会移除指向它的分盘绑定，保留独立单曲关联。
- 修改专辑、分盘绑定在事务内更新 revision。备份恢复验证数字专辑 ID 与 payload、外键及原收藏数据。
- 新结构无法由 0.1.11 或旧 schema 9 预览读取。测试后继续使用新版；如必须回到旧版，需要使用升级前备份，不能将旧版强行打开新数据库。
- 播放列表仍按实体版本标识保留最多三份历史；助手上下曲使用同一份当前列表顺序，并检查 revision，避免使用旧单专辑顺序。
- 不保存新的播放 URL 或登录凭据。继续沿用账号权限和现有凭据管理。

## 封面切换修复

原中央卡片会将侧边已经解码的封面组件替换成共享展示层；缓存未命中或重新解码时，中央短暂显示加载空框。现在浏览时始终保留每张卡片的封面节点，左右移动只改变卡片位置；共享展示层仅在打开详情时挂载。仍只渲染邻近卡片，浏览时不加载 3D 模型，不扩大图片缓存或启动常驻渲染循环。
