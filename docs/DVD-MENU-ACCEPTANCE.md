# DVD 原盘菜单人工验收

2026-10-21。由用户操作。代码接入不等于实盘验收通过。

## 启动

在 PowerShell 运行：

```powershell
& 'E:\ToolsForMyself\DiscAtelier\Test-DVD-Menu.ps1'
```

脚本打开独立测试版，测试库位于项目的 `target\dvd-menu-test\library`，再次启动保留上次测试历史。没有测试收藏时首页为空，这是正常状态。此入口不访问现有收藏库，也不重置前一轮测试窗口中的数据。

设置 → 播放 → **VLC · DVD** 填写 `D:\Program Files\VLC\libvlc.dll`，保存。仅测 DVD 时，MPV 与 MakeMKV 可以留空。测试前请自行停止其他播放器对同一光驱的播放，减少占用；本应用不会替你停止它们。

## 按顺序检查

1. 更多 → 光驱 → 刷新。应显示 DVD 和盘标；点“播放”。视频应在应用内显示，不出现另一播放器窗口。光盘的片头和原有导航顺序保留。
2. 等原盘菜单出现。先使用方向键、Enter 选择菜单项；再点击画面里的原盘按钮，检查选中和实际进入内容是否一致。
3. 播放正片后点控制区“菜单”，应回到原盘菜单；再次选择章节或正片。原盘如果提供音轨、字幕菜单，也分别选择一次并检查实际声音、字幕。
4. 正片暂停约五秒再继续，拖动一次进度，切换音轨。菜单页的进度条应禁用；菜单切换不能把跳过的时长计为观看。
5. 点“全屏”，将鼠标移到画面中间并静止约两秒：标题和控制条应收起，视频画布不缩小。移动鼠标应唤回；下拉打开或拖动期间不收起。
6. 全屏下点一次画面，再按 Esc，应只退出全屏。正常窗口下 Esc 返回收藏并暂停，底部播放入口可重新打开。
7. 正片播放约十秒，记下控制区的 DVD 标题编号与时间。点“菜单”，再停止；光驱 → 播放历史 → 继续播放，应恢复到同一正片标题附近，而不是从菜单按秒数跳转。
8. 关闭测试版，再运行同一脚本。历史应保留；从历史续播，再停止和关闭，确认没有残留声音或无法退出。

如有失败，请提供：步骤编号、界面报错原文、是否有声音，以及画面状态（菜单／正片／黑屏）。不需要执行抓包或自动化。

## 只读边界与验收状态

本轮开发工具没有打开实盘，只运行源码检查、合成结构测试、本地历史测试、构建与无媒体 libVLC 初始化检查。软件光驱入口只枚举和读取索引、播放内容；没有制作媒体副本、刻录、弹出、改区域或固件入口。

以上八项目前均为**待用户验收**。原有 MPV 本地视频全屏验收不替代 DVD 菜单与视频输出验收。多集、多角度、不同区域与不同光驱另行测试。
