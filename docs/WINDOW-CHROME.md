# 自定义窗口栏测试

主窗口取消系统标题栏及白色边框，保留原有导航布局。顶部使用相同深色背景和黑白窗口按钮，不重复显示应用名称。拖动顶部空白区域、品牌或弹窗标题可移动窗口，双击可最大化／还原；搜索框、导航按钮及其他交互控件不参与拖动。

窗口控制由 `ui/WindowChrome.tsx` 集中调用本地 Tauri API，通过现有 `useFloatingLayer` 移入当前弹窗。普通弹窗改为全屏透明宿主和内部面板，面板单独进出动画及滚动，保证窗口控制不会被模态遮挡、裁剪或跟随内容滚动。详情页仍使用原全屏布局和共享封面动画。视频窗口为控制栏预留顶部空间，全屏时隐藏窗口栏。

关闭按钮调用 `Window.close()`，继续触发已有 `playback_exit::event` 的 `CloseRequested` 处理，等待内置网易云服务及播放器退出；没有直接销毁窗口或增加新的退出通道。配置保持 `resizable: true`，无边框缩放由本地 Tao 的 Windows `WM_NCHITTEST` 实现。文件选择取消事件的目标判断、原编辑草稿和列表排序逻辑保留。

## 手动验收

使用 `target/release/DiscAtelier-window-chrome-preview.exe`，不要运行旧预览。这份预览沿用独立测试目录 `com.reversedfuture.discatelier.video-preview`，不读取或迁移正式收藏库。

1. 首页没有 Windows 默认标题框；顶部导航保持原位置，右上窗口按钮大小、颜色协调，列表滚动不带走按钮。
2. 拖动空白顶部、双击最大化／还原、最小化后恢复、拖动四边及四角缩放；搜索、添加、菜单点击不拖动窗口。最大化图标和“还原窗口”名称同步变化。
3. 打开详情、设置及编辑窗口，窗口按钮仍固定在屏幕右上；编辑框自带的“关闭”只关闭编辑，右上“关闭 DiscAtelier”关闭整个应用。
4. 从详情进入编辑，取消封面／截图文件选择器后仍在编辑页；Esc 关闭最上层弹窗并返回原页，Tab 焦点留在活动弹窗内。
5. 视频窗口模式、最大化、进入／退出全屏分别检查画面和按钮；全屏隐藏自定义窗口栏，退出后恢复。窗口关闭继续等待播放及内置服务正常结束。
6. 调整系统缩放或使用应用缩放，核对按钮和窄窗口布局；前后编翻面、列表拖拽仍可正常使用。

本轮不新增数据库迁移，不操作个人库或备份。自动构建及哈希验证记录位于 `artifacts/window-chrome-verification.json`。未启动桌面程序；上述原生窗口交互及视觉效果待用户验收。
