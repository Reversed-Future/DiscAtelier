# 界面与动效规范

## 视觉方向

当前入口为 `prototype/directions/index.html`，页面名称为 DiscAtelier。使用黑色底、白色与少量米白文字；封面和包装承担色彩。顶部仅保留音乐、影像、搜索、添加、更多。中心封面配合左右翻阅，不再使用侧栏或布局选择器。界面由 HTML、CSS 和 JavaScript 绘制。

桌面设计基准 1440 × 960，左右留白 56 px。所有界面文字，包括英文、数字、输入框和菜单统一使用本地 MiSans Regular／Medium，原字体不修改，随附许可。控件高约 36–40 px；页面不添加无意义副标题。

字号和排版优先可读性，不为了风格引入额外副标题。空状态仅保留一句必要状态和一个明确动作，例如“还没有影像收藏”“添加”。只有真实错误或不可用功能才解释原因。

## 页面布局

下表列出完整产品规划；当前只实现收藏浏览、整理、详情和手动添加，光驱与助手保留明确的未接入状态。筛选、统计和辅助入口放入更多菜单。

| 页面 | 主区 | 主要操作 |
| --- | --- | --- |
| 音乐／影像 | 顶栏、统计、筛选、架／封面／表格 | 添加、检索、筛选、切换视图 |
| 想购入 | 带版本的列表，链接、参考价及更新时间 | 打开链接、设为在途、取消 |
| 在途 | 订单或副本列表，付款与收货状态 | 确认收到、补录价格 |
| 详情 | 左侧实物、右侧资料和购入字段 | 检视、编辑、播放、查看版本 |
| 光驱 | 每个设备一行，当前光盘与状态 | 播放、绑定、重新识别、弹出 |
| 历史 | 按日期分组，来源和实际进度 | 继续播放、跳转藏品 |
| 助手 | 右侧抽屉，会话与操作差异 | 提问、取消、批准具体改动、撤销 |

桌面宽度目标不低于 960 px；较窄时顶部重排，详情改为上下排列。缩放时允许滚动和重排，不能让主要操作消失。键盘焦点顺序与视觉顺序一致。

## 架与模型的衔接

架上静态外观 → 选中时轻微前移 → 点击后共享外观进入检视 → 完整模型加载就绪后在同一投影边界接续 → 关闭先收纳再归位。加载时保留原外观，不先闪一个空白 Canvas。

闭合姿态、相机、阴影方向和盒体尺寸是衔接契约。不同模型坐标通过展示配置转换；不能直接对所有模型套同一旋转值。数据模型缓存、纹理上传与镜头动画解耦，重加载不重置用户视角。

竖放视图使用可辨认的背脊；没有背脊时显示作品名与作者，无须伪造印刷文字。鼠标悬停可显示封面预览，键盘选中也必须能打开。静态阴影烘焙或缓存，常驻架子不使用逐帧高成本实时阴影。

## 动效定义

所有状态衔接都设计，不让静态元素持续运动。本次按用户要求，鼠标与键盘触发均保留短过渡；系统减少动态设置优先。菜单开关、表单弹窗、详情取放、标签、分区、搜索、整理和状态切换均有动效。

| 场景 | 时长和曲线 | 可中断行为 |
| --- | --- | --- |
| 按钮按下 | 120 ms，scale 0.98 | 松开立即回弹，无过冲 |
| 选中和悬停 | 120–160 ms，ease-out | 同属性 transition 从当前位置改目标 |
| 菜单／筛选弹层 | 入 180 ms、出 120 ms | 从触发点展开，Escape 立即退出 |
| 详情与抽屉 | 入 240 ms、出 160 ms | 从当前状态反向，不重播起点 |
| 架到检视 | 260–300 ms，受阻尼弹簧 | 保留当前速度，切换选中取消前任务 |
| 模型拆装 | 使用模型真实轨道时长 | 按合法状态机停止／继续，镜头仅一个控制器 |
| 筛选重排 | 180 ms，FLIP，仅可见项 | 输入即更新结果，不等待动画完成 |
| 播放进度 | 跟随真实事件 | 拖动优先，网络进度不抢回手柄 |

统一曲线 `cubic-bezier(0.23, 1, 0.32, 1)`；抽屉使用 `cubic-bezier(0.32, 0.72, 0, 1)`。优先 opacity 和 transform，不写 `transition: all`；大面积 blur、实时阴影变化和布局尺寸逐帧动画不作为默认实现。

当前原型在减少动态模式关闭过渡及位移，不循环飘动、旋转封面或让静态背景持续重绘。正式模型接入后离屏停止渲染，关闭时释放 GPU 资源。错误提示不会靠动画表达唯一信息。

## 输入、焦点与状态

详情与添加面板使用可访问对话框，打开后焦点进入、关闭后回原触发控件。Escape 先退出最上层，模型内部返回、详情关闭、主界面各有明确优先级。表单标签不能只靠 placeholder，错误放在对应字段附近。

搜索按需展开，Escape 清除并收起，保留无结果状态。所有文本输入框聚焦时保持原边框，禁止焦点高亮、光圈或发光；保留文字光标。按钮仍保留轻量键盘焦点提示。下拉选择使用定制列表，支持方向键、Home／End、Enter、Escape、外部点击关闭；Escape 先关下拉，再关详情。原生 select 隐藏保留表单值。浏览器搜索装饰、提示、自动填充配色、选中文字和滚动条均有专用样式。验证错误以页面文字展示。

更多菜单统计当前筛选结果。正式数据源接入时，来源加载、空结果、认证失效、限流、离线将分别表达，过期数据标记更新时间。

## 性能与验收目标

在记录了 CPU、GPU、内存和屏幕刷新率的目标 Windows 设备上验收。目标是主界面交互 p95 小于 100 ms，常规 UI 动效接近 60 fps；这些是验收预算，不是当前已测结果。

性能用 1 万副本、5 万曲目和多模型资产库作基准。架与列表虚拟化，最多加载可视行加缓冲区；选择一个模型后才解压几何和上传纹理。静态书架空闲时不持续 requestAnimationFrame。低配置降级到封面／预渲染模型，收藏和编辑不依赖 WebGL。

测试覆盖快速重复打开关闭、快速筛选、连续选择不同模型、加载中退出、缩放 200%、纯键盘、减少动态、无 WebGL、断网。动画视觉验收需要同时看中间帧和结束状态，不能只测最终 CSS。
