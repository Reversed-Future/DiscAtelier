# 内置网易云静默预启动

内置模式在应用 setup 中安排后台阻塞任务，读取当前接口设置后调用 `Runtime::warmup`。不在窗口线程等待 Node 或 API 模块加载。自定义模式、旧版自定义地址设置及设置读取失败时不启动内置组件；预启动失败不会弹窗或阻止主界面，实际请求仍可重试。

新增应用内部管道操作 `warmup`，加载现有 API 模块后返回 `{ ready: true }`。它不是上游网易云接口，不读取登录凭据，不调用搜索、登录或音源接口，不启动 HTTP 监听。正常查询和预启动共用同一个进程锁，避免用户提前点击时启动两份 Node。退出沿用现有 closing 标记、子进程清理及 Windows Job 机制。

预启动只消除本地进程与模块加载的等待；网络搜索、音源 URL 获取、播放公钥初始化等仍发生在需要时。

## 本机测量

2026-10-26，Node 22.23.3 / 内置 API 4.41.1。运行真实 runner，三个独立空缓存目录，每次 ready 后采样 10 秒。测量进程使用无窗口模式，预加载检测脚本拒绝 TCP 连接和监听；三次均记录 0 次尝试，关闭输入后均正常退出。

这是本机短时空闲采样，不代表所有电脑或搜索、播放时的峰值。常驻成本约为一个百 MB 级 Node 进程，不能称为没有额外占用。测量使用测试缓存，没有操作实际收藏或凭据。

新增回归覆盖不调用上游请求的预启动、反复预启动与请求复用、并发只启动一个子进程、退出后不重新拉起，以及内置／自定义／旧设置选择。构建结果和预览哈希见 ROADMAP.md。
