# 本地文件关联

本地文件关联把收藏库中的一套音乐或影片指向这台电脑上的实际文件，用于在没有光驱或没有原盘时直接播放。

## 流程

1. 在“更多 → 本地文件”选择文件夹；也可在某个收藏详情底部点击“本地文件”，只处理当前这一套。两条入口都可以把绝对路径粘贴到路径框后点击“扫描”。
2. 后端递归扫描子目录，只收集受支持的音视频扩展名；不会跟随目录符号链接，单次最多收集 20,000 个文件。
3. 前端用文件夹路径、文件名、收藏标题和作者计算匹配：
   - `.flac`、`.wav`、`.mp3` 等音频只匹配音乐收藏；
   - `.mkv`、`.mp4`、`.m2ts` 等视频只匹配影像收藏；
   - 标题或作者词元至少命中一个才会自动关联，避免把所有文件塞给第一套收藏。
4. 关联表允许逐行改选收藏，并按专辑轨号顺序展示；未匹配行放在末尾，可以点击“自动关联未匹配”补一个候选，再人工核对。
5. “保存关联”写入数据目录的 `local-files.json`。从已保存行点击“播放”会调用 MPV 打开本地文件。
6. 详情页的“本地文件”只替换当前收藏的绑定，保留其他收藏；每个文件旁的数字框可以单独改集数或轨号，留空表示只绑定文件。
7. 曲目列表每行末尾显示本地播放符号；有网易云歌曲匹配时再显示白色网易云播放按钮。章节列表每行显示本地播放符号；章节本身没有网易云歌曲身份，因此不伪造网易云按钮。
8. 本地音乐点击播放后由原生顶层播放器覆盖详情，详情窗口保持打开；关闭播放器后直接露出同一详情，不经过首页。正在播放的曲目再次点击播放按钮会直接打开播放器。点击任意曲目直接切换，播放器会自动替换当前会话，不需要先停止。播放器的上一首、下一首、播放/暂停和循环在同一行，循环按钮位于右侧。

## 集数／轨号

识别顺序：

- `S01E03`、`S1E3` → 第 3 集；
- `第 3 集`、`第 03 话` → 第 3 集；
- `EP03`、`Episode 3` → 第 3 集；
- 文件名开头的 `03` → 第 3 集；
- `CD03`、`Disc 3`、`Track 12` → 对应轨号；
- `03 - 曲名` → 第 3 轨；
- `艺人 - 歌名` 没有数字前缀时，读取当前收藏的专辑曲目表，按歌名匹配后填入对应轨号，并在关联表中单独显示匹配到的歌曲标题；
- 精确歌名优先于包含匹配：`夏のせい` 不会误配到 `夏のせい (English ver.)`，带 `(English ver.)` 的文件仍匹配到对应英文版本；
- 关联表的歌曲列可以从当前专辑曲目表手动下拉改选；修改轨号时也会立即反查并更新歌曲标题；
- 多碟专辑按曲目表顺序编号；单碟中唯一的 position 直接使用原轨号。

集数或轨号写入关联标签（如“租借女友 · 第 3 集”），同一收藏可以关联多个文件。播放时从关联表选择具体文件。

## 存储与安全

- `local-files.json` 位于 `%LOCALAPPDATA%\com.reversedfuture.discatelier`，内容仅为 `copyId`、绝对路径、显示标签和集／轨号。
- 保存时校验文件存在、扩展名、绝对路径和重复项。
- 播放命令只接受已保存的 `copyId + path` 组合；不能直接播放任意路径。
- 文件路径属于本机数据，不进入 SQLite 备份。换电脑或移动文件夹后需要重新扫描。
- 本地播放复用 MPV 后端；光驱播放链路不受影响。

## 验证

- `tests/local-files.test.mjs` 覆盖 S01E03、中文集数、EP、开头数字、CD/Track、歌名匹配和“未匹配不自动关联”。
- CDP 实测扫描 6 个文件，识别 3 个音乐轨；2 个 Blue Archive 视频文件没有同名影像收藏而保持未匹配，手动选择“租借女友”后正确映射为第 1 集；保存后通过 MPV 播放测试 WAV，播放快照进入 `buffering` 且无错误。
- 测试关联已清空；测试文件位于 `artifacts/local-test`，不进入发布安装包。

## 限制

- 目前按文件路径和名称匹配，不读取媒体内嵌标签或 TMDB 分集表。
- 关联表不自动拆分合集目录；多部影片放在同一文件夹时仍建议人工核对。
- 本地音乐使用独立 CD 式界面，不是 MPV 视频窗口；专辑顺序来自本地关联的轨号。
- 右下角播放列表只在播放本地音乐时出现，不替代网易云播放列表。
