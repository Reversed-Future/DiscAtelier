# 启动时检查更新

应用主界面挂载后通过现有 `update_check` 后端检查 GitHub Release。每次 WebView 启动只自动尝试一次，不等待收藏数据库加载，不阻塞界面；失败不弹错误，设置页仍可主动检查并查看错误。前端合并正在进行的手动与自动检查，避免重复请求互相冲突。

有新版时显示黑白非模态提示，不抢焦点。查看更新打开设置的“关于”页；下载、签名验证、停止播放、备份与安装重启保持原有用户操作流程。自动检查不会调用下载或安装。

提示位于右上角导航下方，出现和关闭使用 180ms 透明度过渡；系统减少动态效果时缩短为 125ms，不移动位置。关闭时保留内容直到淡出结束，同时禁止交互；快速重新显示会取消旧的移除任务。光驱收藏提示复用该动效，并将底部间距从 88px 调整到 56px，拉开与标题、作者的距离。隔离浏览器测试覆盖普通／减少动态效果、进出透明度、关闭时文本保留及中途重新打开。

“忽略此版本”将后端提供的版本字符串原样写入本地 WebView 的 `discatelier.ignored-update-version`。只抑制该版本的自动提醒，不隐藏手动更新、不清除后端待更新信息。后来版本仍提示；“稍后”仅关闭当前提示，不持久化忽略。写入失败时保留提示并显示错误。该键是新增内部 UI 偏好，不是 GitHub 清单字段，不写收藏数据库。

测试使用模拟 IPC 和隔离浏览器上下文，验证每次启动一次、重复挂载复用、忽略跨刷新保留、后来版本提示、手动入口、打开正确设置页、稍后及静默错误，并断言没有下载或安装调用。没有为测试启动安装程序或改动用户的忽略设置。
