# 菜单自动关联与 BD 分盘显示

已纳入 0.1.27 正式发行；下文保留开发与预览验收记录。见 [发布校验](releases/v0.1.27-verification.md)。

2026-10-26，隔离预览，未发行。

## 行为

- 菜单识别后直接在本地已购收藏的曲目内容中查找 Disc 标题，不再只用艺术家匹配整条收藏。完整演出年月日配合场馆／演出标题文字可识别不同写法，例如 `2018.01.10 日本武道館` 对应 `2018 Live / Fogbound 1月10日 日本武道館`。
- 识别置信度达到 80、唯一明确匹配时保存光盘与收藏、Disc 的关联。日期冲突、仅同作者、多个相近结果不自动写入。保存前重新核对盘片；已有明确分盘关联保留，避免重复识别覆盖用户纠错。
- AI 判断、截图、进度及错误显示在对应光驱控制下方。纠正关联可搜索收藏，再选择具体 Disc；也可取消分盘限定或取消关联。识别结果按光驱及盘片标识隔离，不显示到换入的其他盘片上。
- Discogs 的 `BD1-13`、`BD2-1` 按独立分盘处理，CD、BD1、BD2 同级，保留源顺序、完整标题和全部曲目。平铺 heading 与嵌套 index 均支持。标签自动换行，不用省略号裁掉长演出标题。

## 数据与接口

新增内部 `OpticalDisc`（`key`、`label`、`title`）；Disc 标识沿用现有曲目位置解析结果，不改大小写或重写来源键。前后端分盘规则同步扩展 BD 前缀。

Schema 16 为 `optical_bindings` 增加可空的 `disc_key`、`disc_label`。旧绑定保留，迁移前沿用现有 SQLite 完整备份流程；具体 Disc 必须通过当前收藏曲目校验，显示名由存储层生成。收藏本体、曲目内容、来源资料及旧备份不删除。
