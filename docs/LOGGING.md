# 诊断日志

2026-11-02。DiscAtelier 将启动信息、界面错误和未捕获异常写入本地日志，方便用户导出后反馈问题。

## 位置

```text
%LOCALAPPDATA%\com.reversedfuture.discatelier\logs\discatelier.log
```

日志达到约 2 MiB 后轮换为同目录的 `discatelier.1.log`，只保留当前文件和上一份文件。

## 如何获取

打开 **设置 → 数据 → 诊断日志**：

- **打开日志目录 ↗**：在资源管理器中定位日志文件；
- **复制最近日志**：复制最近 160 行到剪贴板，可直接粘贴发送；
- **导出诊断日志**：选择保存位置，导出一份完整日志文件。

## 记录内容

- 应用版本、操作系统和本地数据目录；
- 前端启动信息；
- 界面捕获的错误（统一经过 `errorMessage`）；
- 未捕获的 `error` 和 `unhandledrejection`；
- Rust panic 信息和位置；
- 导出日志不会修改原日志。

日志可能包含本地文件路径、数据源查询文本和错误堆栈。密码、Token、API Key 等常见字段会做遮蔽，但发送前仍建议快速检查。日志不包含数据库、封面、模型或播放内容。
