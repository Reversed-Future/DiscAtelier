# CD 曲目资料

光驱面板和 CD 播放页读取歌曲名、艺术家、专辑、年份／日期、流派、曲号及总曲数。未提供的文字字段不显示，读取失败仍可按真实曲号和 TOC 时长播放。光驱选择框保留歌曲编号、标题和时长，播放页按曲号关联元数据，播放历史保存已识别的标题。不会修改收藏资料。

## 数据来源与边界

- 使用用户配置的 libVLC 3；VLC 的 CD 模块提供 CD-TEXT、MusicBrainz／CDDB 资料，保持原始返回文字，不从截图补写。
- VLC 3 的普通异步预解析会跳过光盘。已实测该接口返回 skipped；因此打开整盘目录入口，禁止音频和视频，读取子项，不选择／播放子曲目。查询结束、失败、超时后释放全部 VLC 资源，不控制正在运行的 VLC 程序。
- 公共 ABI 来自 VideoLAN `3.0.x/include/vlc/libvlc_media.h`、`libvlc_media_list.h`、`libvlc.h`；目录行为和配置来自 `3.0.x/modules/access/cdda.c` 与 `src/libvlc-module.c`。
- 资料查询和设备枚举／实际播放使用独立队列。按盘符、盘片 token 和 VLC 路径缓存；成功一小时、失败一分钟，最多八个光驱条目。“重新识别”可重试。读取前后重新校验盘片，拒绝重复或不在实盘中的曲号。
- 原始 TOC 始终负责曲目数、顺序、时长和播放路由；第三方资料不会替换它。没有资料也不阻止播放。
- 此功能不增加数据库迁移，不改收藏、购入记录或备份。

## 手动验收

1. 打开独立测试版，在光驱面板刷新。若独立测试设置尚未配置 VLC，在播放设置填写现有 `libvlc.dll` 路径。
2. 等待识别，选择框应显示三首完整歌名和时长；选择任一首可查看艺术家、专辑、年份和曲号。
3. 点击播放，检查列表标题、上一首／下一首及底部播放标题；停止后检查播放历史标题。
4. 换盘或弹出光盘后刷新，不应把 Lemon 的资料放到另一张盘上。网络不可用时保留按曲号播放，恢复后可重新识别。

自动检查及预览构建结果见 `artifacts/cd-metadata-verification.json`。实际界面交互和声音输出由用户验收。
