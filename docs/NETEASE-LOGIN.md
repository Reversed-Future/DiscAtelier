# 网易云扫码登录预览

2026-10-21，本地预览；未发布安装包，数据库仍为 schema 8。

## 使用

完全退出旧版，打开 `E:\ToolsForMyself\DiscAtelier\target\release\DiscAtelier-netease-login-preview.exe`，保留旁边的 `netease-runtime` 目录。

1. 设置 → 网易云，服务选择「内置」并保存，点击账号右侧「登录」。
2. 使用手机网易云音乐扫码，在手机上确认。设置中显示昵称，二维码收起；无需额外点击保存。
3. 返回已匹配曲目的收藏，停止已有的试听播放，再点击歌曲重新获取音源。播放请求携带账号凭据，实际完整音源、音质或试听由网易云返回的账号权限决定。
4. 手动测试播放、暂停、拖动；退出软件后重新打开，检查昵称和登录状态仍在。
5. 点击「退出」确认昵称消失；网络不可用时也会清除本机保存凭据。关闭扫码区域、离开该设置页或刷新二维码后，旧会话不能再写入凭据。

真实手机授权和账号完整音源尚待用户测试；自动测试不代表已经登录用户账号或实际出声。没有操作窗口或光盘。

## 实现与边界

- UI 只接收临时二维码图片、扫码阶段和昵称，不接收 Cookie。二维码在设置内展开，过期可重新生成，取消／收起有动效，支持减少动效偏好。
- Rust 维护五分钟本地会话上限和至少三秒的轮询间隔；每次网络返回后再核对会话，防止取消／刷新后的迟到结果保存凭据。
- 使用 api-enhanced 4.41.1 已核对的 `login_qr_key`、`login_qr_create`、`login_qr_check`、`login_status`、`logout`。扫码码值 800／801／802／803 分别表示过期、等待、待确认、成功。只保留上游文档指定的 `MUSIC_U` 认证 Cookie。
- 凭据保存到 Windows 凭据管理器：服务 `com.reversedfuture.discatelier`，项 `netease-music-u`。不写入 JSON 设置、SQLite、收藏备份、日志或前端存储；不通过命令行或环境变量传递。Rust 与内置 Node 之间使用现有私有进程管道。
- 每次带凭据播放前核对登录状态。过期后提示回设置扫码，不静默退回游客试听。账号信息请求失败不会清除已保存凭据；退出登录会先清除本机凭据，再尝试服务端退出。
- 扫码凭据仅供内置服务使用，不发送到自定义 API 地址或 AI 助手。切换到自定义服务不使用这份账号；切回内置后仍可检查或退出。
- 本次不增加密码登录、自动刷新扫码凭据、音质选择或付费权限变更。上游文档明确普通登录刷新接口不支持二维码凭据，失效时重新扫码。
