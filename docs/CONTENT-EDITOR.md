# 自定义资料编辑

2026-10-26。编辑版本弹窗增加“资料”页，允许直接修改已获取并保存的内容。

## 音乐

- 流派、风格；
- 简介；
- 曲目位置、标题、时长，增删曲目；
- Credits 姓名、ANV、角色、关联曲目，增删；
- 公司名称、类型、品番，增删。

保存写入 `edition_content`，之后详情曲目、本地文件关联和搜索都会读取修改后的内容。

## 影像

- 选择要编辑的作品来源；
- 标题、原名、简介、首播日期、集数、海报地址、类型；
- 资料条目：标签和值（值支持一行一个，`文本 | 链接`）；
- 图片：类型、地址、预览地址、语言、宽高；
- 人物：姓名、角色；
- 角色：姓名、角色、声优、角色资料、头像地址；
- 章节：组、编号、标题、原名、日期、时长、简介。

角色头像支持两种来源：

1. 网络图片地址；
2. 本地 PNG／JPEG／WebP，读取后作为内嵌 data URL 保存，单张上限约 700,000 字符。

本地头像随该收藏资料一起写入 `video_work_metadata`，不新增数据库表；备份会包含它。

## 边界

- 作品来源标识、分盘结构和实体版本字段仍在“版本”页处理；
- 未在表单中暴露的原始嵌套字段会原样保留，不会被保存操作清空；
- 音乐曲目/章节修改后，搜索索引会在下一次搜索时重新读取；
- 编辑保存沿用现有 revision 冲突校验，详情过期时提示重新打开。

## 验证

- 结构化字段加载和保存命令通过 TypeScript／Tauri 构建；
- 音乐《Lemon》资料页读取 41 条曲目，保存后弹窗正常关闭；
- 影像《蔚蓝档案 动画版》资料页读取 21 个角色、12 个章节；
- CDP 检查编辑页两个标签、资料区和滚动区域。
