# 验收与交付

在创建的工作区执行，文件参数替换为实际导出路径：

```text
node scripts/validate-package.mjs <最终包.ateliermodel>
python scripts/validate-images.py <最终包.ateliermodel>
```

结构检查使用随包真实 parseModel，不解码图片；图片检查需要 Pillow，真正解码并保守核对预算。都不读取收藏库。缺依赖应说明，不跳过后写“全部通过”。

## 分层证据

1. **文件**：最终字节数、格式、SHA-256、结构及图片检查结果。
2. **渲染／动作**：预览页用“载入模型包”重新读最终文件，不只运行制作源。检查正反面、边缘、贴图与材质；正常时长取出、放回、全部收起；连续翻页保持用户视角。减少动态模式不能验证中途穿模。
3. **目标应用**：在授权的测试收藏上传模型、保存、离开再打开，检查动作和返回架位。记录软件版本；不要直接改 SQLite 或覆盖未经授权的正式收藏。只能浏览器测试时写“原生导入未验证”。
4. **实物认可**：用户对当前修订的结构、材质和操作作出认可。没有回复不算通过；无需为了未取得认可而拒绝提供已完成的文件。

修复后重新导出、重新计算哈希，旧截图不当成新版本证据。保留原图、历史包与当前工作区；不批量删除，不自动上传。

## 交付

- `.ateliermodel` 最终包、可运行本机预览及其许可证。
- 几何／材质／动作制作源、处理后贴图、原照片映射。
- 使用说明：比例单位、目标软件、操作顺序、经授权的估计与限制。
- 验收记录：文件哈希、实际测试命令与结果、原生导入状态、用户认可状态。

遇到缺失资料或环境限制，保存已有成果，指出准确的缺项和用户下一步操作。不要通过关闭校验、改 profile 或删掉问题部件让测试“通过”。
