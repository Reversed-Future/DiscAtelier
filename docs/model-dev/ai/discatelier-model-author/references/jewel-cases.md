# 常规单碟／多碟透明硬盒制作

本参考用于用户选择的常规透明碟盒，口头称“透明亚克力盒”也可按此交流；具体是亚克力还是其他透明塑料，不仅凭名称判定材料参数。目标是有厚度、铰链、碟位和真实动作的可导入三维盒，不是把照片贴在长方体上。

## 先确认这几项

| 内容 | 向用户取得的依据 |
|---|---|
| 碟片与布局 | 单碟／双碟／更多碟；开盒正面、翻动每层托盘后的照片；两张碟是否位于同一翻转托盘两面 |
| 盒型与尺寸 | 闭合宽×高×厚、铰链在哪侧、开启方向；厚型多碟盒不能直接沿用薄型单碟盒深度 |
| 托盘 | 透明／黑色／有色，固定／翻转／可整体取下；转轴位置与正反碟位；托盘和后壳一体还是分体 |
| 印刷与底纸 | 封面在歌词本、独立字卡还是印在盖上；背面曲目在底纸还是后壳上；底纸是否允许取出及需要先移开哪些物件 |
| 歌词本 | 完整页序、正反映射、宽高与装订方向；没有歌词本就不额外生成 |
| 其他 | 腰封有无、展开宽度与折线、前后覆盖范围；附卡和赠品是否在盒外 |

用户可以提供实测尺寸，也可以明确授权沿用其指定的一套或按参照物比例制作。历史《人间开花》使用过 14.1×12.5×1 cm 的盒体；这是该作品数据，不是所有碟盒的默认标准。不能静默套用其纸厚、碟径、托盘、页数或腰封尺寸。

先确认概览和碟位，随后按缺口补问。常规单碟不需要用户填写特殊布料、解密卡等无关资料。

## 几何与分层

使用统一单位和 Z 轴向上，按实际结构定义节点；以下名称是物理部件说明，不是软件内置 id：

1. **后壳与外沿**：底板、侧墙、边缘唇口、书脊侧结构；有厚度和浅圆角。后壳印刷、底纸及塑料面分层，留真实间隙避免闪烁。
2. **前盖**：薄板、侧翼、歌词本卡扣与铰链。铰链轴放在真实接合边；盖面相对轴偏移，开盖围绕轴旋转，不能绕盖中心悬空旋转。
3. **托盘**：主体、容碟凹位、中心卡齿／卡座、取碟指槽和侧边卡扣。圆形凹槽要有深度，不用深色圆贴图代替。透明托盘背后的底纸可见但不能穿透实体结构。
4. **光碟**：有中心通孔、薄厚度、正反表面和边缘；正面印刷按实物，背面及裸银区域使用随角度和光照变化的反射。不能把中心孔涂白冒充孔洞。
5. **歌词本／纸卡**：实际厚度、双面页和装订轴；封面不能同时当盖面印刷重复出现。抽出后再阅读，翻页保持稳定跨页视角。
6. **底纸**：按实际背面与两侧折边连续成形；固定底图不提供取出操作。可拆底纸需有物理出口，托盘挡住时先处理托盘。
7. **腰封（若有）**：前片、脊片、后片沿折痕连续连接；宽背片与窄背片按照片确认。取下时先脱离盒体，不直接穿过盒壳。

透明壳使用 V2 支持的 physical 材质字段，如 transmission、roughness、thickness、ior；先读校验器精确字段。参数按实物对比校准，不用高 opacity 或低粗糙度把所有塑料做成厚玻璃。边缘靠真实厚度、法线与光照体现，避免人为叠加一圈不透明白框。正常反射、高光和环境光由运行库处理，底图只保留印刷／本色信息。

## 单碟与多碟的区别

### 单碟

常见流程是打开前盖，分别操作左侧歌词本与右侧光碟。仍要以照片确认左右位置、托盘颜色与一体结构。取碟先沿卡座法向抬起，完全离开卡座和外沿后才横移和翻转；放回沿原路径逆序。歌词本取出方向避开卡扣，不能穿过前盖。

### 双碟或更多碟

先画“第几张碟 → 哪层托盘 → 托盘哪一面 → 转轴在哪 → 前置动作”的明确映射。多碟不能只是复制圆盘后沿厚度堆在一起。

- 同一翻转托盘的两面装碟：托盘有自己的转轴；装在其上的碟随托盘运动。背面碟只在托盘翻到可操作位置后可点击。确认是否允许带碟翻托盘，不自行规定先取下全部光碟。
- 多片翻转托盘：每层厚度、枢轴、限位和翻转顺序来自照片。开角留足空间，翻转中检查碟边与邻层、歌词本和壳体不相交。
- 左右独立碟位、厚盒或多个盖片：按实物分容器和开合动作，不能强行套用双面托盘结构。
- 每张碟独立取出、查看、收回；取下一张不应自动移走其他碟。托盘关闭时，尚在外面的光碟如何重新放回要有明确可达路径。

V2 节点运行时不能改父级。可用共同装配根节点存放可取出的托盘与光碟，在动作里同步烘焙装在托盘上的碟姿态；取出后停止随托盘联动。也可先在制作场景模拟父子关系，再用 `record-scene.js` 烘焙成固定父级的轨迹。不要只在预览中临时 reparent，却导出不完整的动画。

## 状态与验证

单碟／多碟都优先导出 V2，沿用 authoring.md 的 `partInteraction`、明确 `part/view`、独立 `returns` 和收纳依赖。按真实装配限制生成可达状态；多碟增加独立部件后注意 768 状态和 4000 动作上限，不能通过遗漏独立收回或强迫全景单线播放来掩盖超限。

至少覆盖：

- 闭合正反面、开启侧视、空托盘和各碟位。透明边缘、纸张图案、卡座和指槽没有错位或桌面残留。
- 每张碟逐一取出、放回；合法顺序的多件同时在外；托盘正反翻动及由不同中间状态全部收起。
- 装在托盘上的碟随托盘走，已取出的碟留在其位置；不能穿模、悬空失联或同时出现在两个碟位。
- 纸卡／歌词本／可拆底纸／腰封分别可操作，固定部件不会误取。连续翻页不切全景。
- 旋转相机后透明材质和银面反光变化，文字保持可读。最终包在 DiscAtelier 中导入、保存、重开以及用户验收。

## 何时转为深入还原

用户要求特殊外盒、抽拉机构、复杂插舌、非标准卡扣、特殊透明插页、解密叠层、布料或塑封细节时，解释新增部件与所需资料，确认其需要深入还原。用户已明确要求深入时直接执行，不再重复问选项。

深入程度与包版本分开：能完整表达的深入模型仍可 V2；V3 必须满足目标应用的固定结构兼容约束。常规方式同样要让用户满意，不能把已确认的实物细节当作可忽略项。
