# 资料确认与还原

## 先看资料，再分批提问

整理一份部件表：实物名称、明确的新内部 id、正反／侧面文件、物理尺寸与单位、厚度、材质、上下层次、固定或可取出、开口、折线／铰链、当前证据和待确认项。新定义的 id 与软件已有字段区别记录；已有 id 必须从实物项目定义读取。

可按需要向用户索取：

- 外盒闭合正反面、四侧、打开过程、内部空盒，以及取出全部物品后的照片；大尺寸物件放尺子或提供至少一条已知尺寸。
- 每件物品宽×高×厚，碟片直径／孔径，内托凹槽深度、包装内外尺寸、纸张与透明片厚度、绑带宽度和位置。比例照片无法确定厚度时单独询问。
- 歌词本完整页序、封面封底、透明插页各自正反面及叠放后的效果；重复拍摄不要当成额外页。确认装订边和向左／向上翻。
- 海报展开全图、背面、折线网格与折叠顺序；确认收纳时露在外面的具体一格。
- 标签、腰封完整展开图与折痕；透明／镂空配件的实际外轮廓、挂孔和背面。
- 材质在两个以上视角或照明下的照片／短视频，用于分辨印刷色、金属裸面、普通签字笔、磨砂、透明油墨、丝绸、橡胶和塑封。
- 收纳层次与物理依赖：哪些连接、哪些固定、谁先取出、插舌从哪边拔出、封口朝哪边，不能从一个正面照猜整个结构。

确认位置时统一使用实物正常阅读方向，记录“从正面看／从背面看”、安装在哪一层、距对应边的距离或比例、标签长边朝向及文字方向。标签竖贴不等于旋转任意 90°；背面视图不能直接套用正面的左右坐标。塑封封口还需确认薄膜从哪面延伸、绕过顶部后贴在哪面。用户框选位置应落到部件坐标中，补正反及侧视图核对。

可以用标注图询问关键点。用户无法补拍时，利用已有完整边缘校正透视；仍不可见的信息说明不确定范围，询问是否允许估计，或暂留未完成标识。不要把补拍作为唯一推进方式，也不要未经同意生成缺失文字。

## 图像与材质处理

- 按整张纸或物体外轮廓定位边界，包含透视和弯曲。四角单应变换不能消除书脊局部弯曲时采用边缘网格展开；检查四边是否残留桌面、书脊阴影或错误折痕。处理流程和参数留在制作源。
- 图案与几何边界分开：亚克力按真实透明描边轮廓建模，印刷层保留自己的透明度；不按卡通人物色块的凸包切外壳。
- 白平衡参考用户提供的中性材料，保留原照片及另存校色副本。只授权数值校色时不使用生成式重绘；需要重建或移除拍摄高光而涉及图像编辑时，按环境的图片编辑工具要求操作，或采用明确授权的数值方法。Skill 不覆盖工具自身限制。
- 纸张通常以高粗糙度为起点，再按实物调整，不默认过曝亮白；奶白自封袋要有相应不透明度／透射，而非完全透明玻璃。
- 印刷颜色与环境反光分离。光碟小人若是未印刷的银面，使用金属区域／反光材质，不把拍照时彩虹固定在贴图。普通笔签名、普通金色印刷不能默认做金属。
- 丝绸包覆海绵需要真实松弛褶皱、转折和接触面；纹理只辅助，不能用高光照片贴在平面或绷紧的表面冒充。当前通用材质无法忠实还原时反馈兼容取舍。
- 塑封是独立透明薄层，有接缝、轻微褶皱及随观察变化的反射；不把印刷上的高光再叠成双重反光。
- 透明插页应单独建层，纸页自有印刷保留；与相邻页对齐后检查整幅轮廓、遮字和“一人一影”等效果。解密必须由实际叠层、孔位和配准产生，不能在操作时直接替换成一张解密成图。

每条材料结论标注“用户说明”“照片可见”“实测”或“用户授权估计”。低信息处应向用户索取，而不是自动填成通用盒。

书册及分切页按 [页面边界与书册](paper-pages.md) 处理。光碟文字的提取另须查看小字近景：先对齐不同角度的照片，区分字形与高光、划痕、颗粒；不要靠提高阈值把细字变成脏块或擦掉。补拍应针对缺失区域和避光角度，已有照片足够时先利用它们。金／银底、印刷字和中心环独立分层，叠层不能有重叠共面表面造成闪烁或自阴影污迹；裸金属文字本身有反射时也按实物处理。
