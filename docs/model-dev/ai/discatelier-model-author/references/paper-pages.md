# 页面边界与书册

用于歌词本、画册、折页及独立分切页。结构接口见 [制作与交互](authoring.md)，交付证据见 [验证与交付](acceptance.md)。

## 先区分照片、印刷面和物理纸张

建立映射：原照片 → 去重后的印刷面 → 物理纸张正反面 → 装订边／分切位置 → 纹理与节点。连续编号未必是独立纸张；重复拍摄、透明插页、封面内侧和封底内侧必须单列核对。

“上下两图”不能据此判定为分切纸；确认能否独立翻动。独立上下页要分别记录切口边缘、厚度、正反面与层序。先试做封面、一个普通跨页、一组分切页和封底，核对方向与纸张对应，再扩展全册。

## 曲边校正不能只拉四角

1. 在原图上标出本页完整外沿，包括弯曲的上、下边和书脊侧边。白边也是页面内容；不能沿图案边界裁掉白边，也不能把露出的邻页当成它。
2. 平直纸张可用单应变换；书脊卷曲、弧形上下沿要用边缘网格展开等方法，保持目标整页宽高。用户标注边界优先于自动识别；自动边缘结果必须叠回原图检查。
3. 分切页的上半下沿与下半上沿可能因翘曲各有一条曲线。分别定位、展开到各自半页区域，再对应几何切口；不能用一条水平线把照片中的弧形桌面带一起分进去。
4. 每批导出后查看全页缩略图和四边、四角、书脊、分切线的近景。自动检测只辅助找异常；同色邻页、浅色桌面或指尖不能只靠色阈值判断。
5. 跨页连续图以同一图案位置、地平线、线条和比例校准两边，再分配到各面；保留实际装订缝，不能用拉伸或删掉图案换取接缝对齐。

白边宽度依据照片中的真实纸边与图案边判断，不为整齐统一裁窄。弯曲矫正应恢复整幅页面，不能用缩小有效页宽来隐藏手指、桌面或邻页。

## 遮挡与拍摄痕迹

- 纯色纸边被手指遮住：获得相应修补授权后，用邻近同材质颜色及缓慢变化的明暗补齐，保留原页宽；先区分纸色与手指阴影。
- 非纯色的小遮挡：确认授权范围，记录修补位置；局部修补限于缺失边缘，不改动可见正文、人物或图案。遮住关键文字／主体时索取补图或说明缺失，不能当作邻近纹理填满。
- 保留原图、边界控制点、局部修补区域、页序映射及最终输出来源。历史中间图不作为当前结果；复查必须针对真正写入包里的纹理。
- 工具使用遵守当前环境和用户授权。允许局部修补不等于允许重绘整页或生成缺失文字。

## 从纸张到运动

纸张正反面、铰轴、厚度和层间距采用同一套尺寸。翻页时图案随同一张网格运动，打开与合拢不能换贴图、换纸来掩盖层序错误。封面／封底厚度与普通纸不同，检查书脊附近转动空间；折叠后最上面仍须是正确的同一面。

检查中间角度的相邻页、上下半页和封面相交，不只看闭合与展开终点。包围盒适合初筛；形变网格的包围盒可能包含未激活形变范围，近距离疑点需检查当前权重下的实际顶点／表面与渲染，区分装订接触和穿透。测试记录采样范围，不能把离散采样说成实时物理保证。

## 独立翻页与格式预算

先估算可达组合，再选格式。例如 40 张上下独立纸，各有 41 个翻阅位置，仅分切段就有 41 × 41 = 1,681 种组合；这不是要求每本书都使用该数量或 V4。

若超出目标格式限制，不删页、不强制上下同步来伪装完整实现。先看目标程序是否已有独立控制器支持；没有时向用户说明缺口，取得扩展授权后才修改程序。V4 的支持边界见 [制作契约](authoring.md)。

收纳阶段，封面和页边的命中应触发整本书的下一步拆装；取出进入阅读后，命中对应页片才翻页。离开阅读或收回容器前，按合法依赖先合书。验证上页领先、下页领先、左右反向翻、分切段首尾与普通页衔接，以及其中途收回；不让两个控制器同时处理同一个点击。
