# GLB、OBJ、FBX 直接导入

从 **DiscAtelier 0.2.4** 起支持直接导入 GLB、OBJ、FBX。

在添加收藏或编辑版本时选择「上传模型」，选中 `.glb`、`.obj` 或 `.fbx`。应用读取原文件，检查关联资源，渲染预览后保存。无需先转换为 `.ateliermodel`。

| 文件 | 当前支持 |
| --- | --- |
| GLB | glTF 2.0 场景、材质、贴图和读取器支持的内置动画 |
| OBJ | 几何、多物体、MTL 材质及关联贴图；没有原生动画 |
| FBX | 二进制及 7.x 文本文件，读取器支持的几何、材质、内嵌或外部贴图、动画 |

## SketchUp 模型

在「编辑版本 → 模型」中可直接选择 `.skp`，无需安装 SketchUp。支持 2017 二进制格式与可解析的 ZIP 容器，已验证 2024、2026 文件。其他版本按实际容器和解析结果校验，不仅依据年份放行；不兼容或损坏的文件仍会提示导出 GLB、OBJ。

支持实体面、组件层级与变换、正反面材质，以及内嵌 PNG、JPEG、BMP、WebP 贴图。BMP 和 WebP 会转换为 PNG 用于显示，完整 SKP 原文件保持不变；隐藏的面和组件不会显示。

导入时会生成用于显示的 GLB，同时保留完整 SKP 原文件。组件位置和米制比例保持不变，预览会自动取景。原文件与显示资源一起保存在收藏和备份中，合计不能超过 50 MiB。

SKP 以静态模型展示，不包含 SketchUp 的场景切换、线框、标注、剖切和插件行为；曲面采用面法线，渲染效果可能与 SketchUp 的样式不同。需要开盒、拆装等交互时，请制作 `.ateliermodel`。

取出后可旋转、平移、缩放和重置视角。有动画时可选择动画片段、播放、暂停、停止。自动取景只调整显示容器，保存的原始坐标、层级和文件字节不变。

## 材质和贴图

- 保持模型内部记录的相对路径。资源放在主文件所在目录或其子目录中；应用不搜索相似文件名，不按名称猜配。
- OBJ 的 `mtllib` 应逐行指定 MTL 文件；带空格的文件名可以保留。MTL 中的贴图路径相对该 MTL 所在目录。
- FBX 优先采用文件记录的 `RelativeFilename`。没有该字段时采用 `Filename`；绝对路径需要在建模软件中重新链接为相对路径。
- GLB 可以使用内嵌资源或目录内相对 URI；不下载远程贴图。
- 缺失资源、损坏图片及当前不支持的图片格式会报错。PNG、JPEG、WebP 是建议的贴图格式。
- 本次暂未接入 Draco、Meshopt、KTX2/Basis 压缩解码器；需要这些扩展的 GLB 会明确提示。Blender 工程不能直接导入。

主模型及关联资源合计最多 **50 MiB**，最多 256 个文件。渲染检查限制为 500 万个顶点、1 万个几何对象，贴图单边最多 8192 像素、总计 128 Mi 像素；超过时需先简化。

## 与拆装模型的区别

原格式模型直接显示其场景和已有动画。应用不会从几何形状推断插舌、碟片、歌词本，也不会自动补出取出、收回和独立翻页规则。需要这些实物交互时，继续使用 `.ateliermodel` V2/V3/V4。

保存到收藏库的是原文件与实际引用资源的不可变副本，内部以 `discatelier-source-model` 记录封装原字节；不转换为 V2 场景或固定装配模型。备份包含这些资源，原始文件夹移动后仍可查看。没有模型脚本执行入口。

## 兼容性验收

已用自建样例验证 GLB 贴图与动画、OBJ 多物体和嵌套贴图、FBX 文本与二进制读取；另用 Three.js r186 的 `RotationTest.fbx` 与 `monkey_embedded_texture.fbx` 验证动画及内嵌贴图。原生流程覆盖预览生成、保存、取出、放回、备份恢复和重启。

这些测试不意味着所有建模软件的扩展、材质节点或 FBX 导出选项都能无损还原。遇到不兼容文件，应保留报错和源文件，在具体文件上定位问题。
