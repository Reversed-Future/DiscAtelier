# V3 固定装配

<p class="lead">V3 调用应用内置的固定装配程序，不是任意模型的新版通用格式。</p>

## 包头与资源 {#header}


固定字段为 `format: "atelier-interactive-model"`、数字 `version: 3`、`rig: "album-assembly-v1"`、数字 `runtimeVersion: 1`。这几个版本概念互不等价，不能只把 V2 的版本数字改成 3。


另含 `id, title, creator, cover, profile, images, textures, data`。images 是 `{id, image}` 数组，image 为内置 PNG／WebP；textures 是 `{id, image}` 数组，这里的 image 是 images 的 ID 引用。多个贴图槽可以指向同一张内置图片。

## 做新的包装时 {#new}


陌生包装优先用 V2。不能借用一个白名单 profile 并替换图片，就声称结构已适配。V3 的几何、资源含义、动作与尺寸有固定约束。


如果所需结构不在支持列表中，请使用 V2 制作，或等待支持该结构的应用版本。模型文件本身不能给应用增加新的 V3 装配程序。


## 当前交互 {#controls}


与 V2 一样直接点击部件拆装、点击书页翻动、拖动旋转、滚轮缩放。根据当前状态使用“放回”“返回”或“全部收起”；部分专用结构还提供对应的特殊动作。
