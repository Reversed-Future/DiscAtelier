# 让 AI 帮你制作

把素材、尺寸与操作要求交给 AI，让它按真实格式制作、导出和验证。这里同时提供完整 Skill 和普通提示词；只有文字聊天能力的 AI 可以协助规划，但不能据此宣称已生成模型或完成渲染验收。

## 下载与选择 {#download}

- [下载完整 AI Skill](downloads/discatelier-model-author-skill.zip)：包含 `SKILL.md`、参考文档、创建脚本、完整制作工作区及许可证。
- <a href="ai/discatelier-model-author/SKILL.md" target="_blank" rel="noopener">查看 Skill 正文</a>：先了解它会做什么。
- <a href="downloads/AI-PROMPTS.md" download>下载通用提示词</a>：适合粘贴给不支持 Skill 的 AI。
- [单独下载制作入门包](downloads/discatelier-model-starter.zip)：手动制作或给已有工具的 AI 使用。

Skill 名称为 **`discatelier-model-author`**，适用于 DiscAtelier 0.3.1 的模型制作、修正和检查。

## 在支持 Skill 的客户端使用 {#use-skill}

解压完整 ZIP，将其中的 `discatelier-model-author` 文件夹交给客户端的 Skill 安装入口，或放入该客户端实际配置的 skills 目录。保留 `scripts`、`references` 与 `assets`；只复制 SKILL.md 无法获得随附的导出环境。不同客户端的安装入口不同，以实际设置为准。

在 Codex 中可显式调用 `$discatelier-model-author`，然后附上素材和任务要求。其他客户端请使用其实际支持的技能调用方式；也可让 AI 直接读取 Skill 文件及所引用的资料。

::: tip 原图与目标版本要一起提供
素材至少说明正反面、尺寸单位、包装结构及期望动作。没有尺寸时写“未知”，指定哪些部位允许估计。提供实际软件版本，避免 AI 把 V3 当成任意新模型都能用的通用升级格式。
:::

## 如何填写任务 {#prepare}

1. 把下面方括号中的内容替换成真实信息，不保留示例路径。
2. 附照片、已有制作源或最终包；无法读取的附件应让 AI 明确说明。
3. 指定新输出目录与允许的测试环境。用户自己的收藏不默认作为测试库。
4. AI 有足够资料后应继续制作；缺关键结构时具体提问，不重复征求已经给过的授权。

## 从照片制作新模型 {#new-model}

```text
请使用 $discatelier-model-author 制作可导入 DiscAtelier 的实体模型。
目标软件版本：[填写实际版本]
素材目录或附件：[填写实际位置]
包装类型、尺寸和单位：[填写；未知请标注]
需要的交互：[例如取腰封、开盖、取出光碟、翻页、独立放回]
允许估计的部分：[没有则填无]
输出工作目录：[填写新目录]

先读取 Skill、素材和真实导出接口，整理部件与缺失信息；关键尺寸或未见结构不要自行编造。先确认采用常规单／多碟透明盒，还是深入还原特殊结构。默认采用 V2；确认是已注册固定结构时才用 V3；独立分切页可用 V4，但目标播放器必须支持（0.2.3 起）。完整校正纸页曲边，保留原有白边，不混入桌面、手指或相邻页。按单一职责拆分制作源，保留原图。交付最终 .ateliermodel、制作源、贴图、可运行预览及哈希。重新载入导出包验证正常速度拆装，并区分结构预检、图片解码、原生导入与用户认可，不把网页截图当成全流程验收。
```

## 修正已有模型 {#repair-model}

```text
请使用 $discatelier-model-author 修正这个模型。
制作源与模型包：[填写实际路径]
目标 DiscAtelier 版本：[填写]
操作步骤与现象：[例如打开盒盖后取出光碟穿过盒底]
期望结果与参考图：[填写]
必须保留的部分：[填写]
输出到：[新的修订目录]

先复现并定位到实际节点、动作或贴图，不根据相似名称猜字段。修改相关制作源，不覆盖原包或改应用校验器。重新导出后验证受影响动作、反向归位、全部收起和原有交互；给出新旧变化、最终 SHA-256、实际检查和未验证项。
```

## 检查最终包 {#audit-model}

```text
请使用 $discatelier-model-author 检查以下最终模型包，不修改模型或收藏。
模型包：[填写路径]
目标 DiscAtelier 版本：[填写]
制作源和素材（如有）：[填写]
允许的环境：[例如只允许独立浏览器预览；或已授权的测试收藏]

读取真实校验器，运行结构检查与图片解码；重载最终包，检查正常速度的取出、放回、全部收起、翻页相机与资源完整性。按文件、渲染动作、原生导入、实物认可分开报告证据。不能执行的检查标为未验证；不写入个人数据库、不修改应用、不删除任何文件。
```

## AI 不支持 Skill 时 {#without-skill}

```text
请读取我附带的 discatelier-model-author/SKILL.md 和其中与任务有关的 references，按其模型制作规范完成任务。如果你不能读取附件、运行代码或渲染，请先说明实际能力，不能声称已经导出或验收。
任务：[填写新建、修正或检查]
目标软件版本：[填写]
素材、模型与制作源：[填写或附文件]
尺寸和交互要求：[填写]
输出目录及测试授权：[填写]

使用完整随包工具；标识符、格式字段和 V3 槽位以真实源码为准。最终交付实际 .ateliermodel 和可复现制作源，分别说明结构、图片、动画、原生导入和用户认可的验证状态。
```

## 看 AI 的交付是否合格 {#review}

应拿到实际 `.ateliermodel`、制作源、可运行预览、最终哈希和检查记录。报告要分清文件校验、真实渲染、桌面上传保存重开与实物认可。只给效果截图、说“JSON 没问题”、或把版本号改为 V3，都不足以证明可导入。

收到模型后，按[验证与导入](validation.html)检查导出文件与实际操作。有问题时将具体步骤、截图或报错交给 AI，使用上面的“修正已有模型”提示词继续调整。

本次 Skill 已包含完整曲边校正、白边保留、分切页、真实表面点击、最终包哈希与交付副本核验。V4 使用独立控制器，旧版不会自动获得支持；请同时阅读 [V4 独立控制器](v4.html)。
