# 测量与素材准备

<p class="lead">先确定这个物件如何组成、如何打开，再开始绘制。</p>

## 记录每一个部件 {#inventory}


常规透明盒先确认单碟／多碟、碟位、翻托方向、铰链、腰封与内页。复杂包装还需列出抽屉、信封、插舌、海报、卡片、挂件等连接与收纳顺序。一个实体有几张光盘，与收藏资料里的 Disc 编号是不同层面的信息；模型不会自动生成曲目分盘。

<table><thead><tr><th>记录项</th><th>需要的内容</th></tr></thead><tbody><tr><td>尺寸</td><td>宽、高、厚度、孔位、折线位置；统一单位和比例换算。</td></tr><tr><td>连接</td><td>固定还是可取出；旋转轴、滑出方向、先后依赖。</td></tr><tr><td>材质</td><td>纸张、透明塑料、磨砂托盘、金属膜；表面与边缘分开记录。</td></tr><tr><td>图片</td><td>正反面、侧边、打开状态、标签四角、内页顺序。</td></tr><tr><td>不确定项</td><td>缺图、不可测部位，以及作者明确同意的估计和取舍。</td></tr></tbody></table>

## 照片与贴图 {#photos}


保留原图，在工作副本上做透视校正、裁边、色彩整理和贴图切分。为每张贴图记录原照片与对应部件。完整保留标题、标签边缘和文字，不用裁掉内容的方式压缩体积。


正面、背面和书页分别确认阅读方向，避免镜像文字。已有照片上的反光不等于材质反射：过强的固定高光应在素材处理中评估，否则旋转模型时高光仍贴在纸面上。


## 比例与厚度 {#measurement}


V2 不固定物理单位。你可以规定“1 场景单位 = 1 厘米”，但几何、动作距离、纸厚与孔位必须遵守同一个换算。记录这个约定并随制作源交付；不要把测量结果只藏在一组魔法数字里。


透明盒要有真实厚度、铰链与底托，光碟要有中心孔。纸套要有开口、背面和边缘。不能用一张照片平面代替需要开合的立体结构。


## 拆装顺序 {#plan}


画出一条实际可行的操作链，如“取下腰封 → 打开盒盖 → 取出歌词本／光碟”。同时定义从任意已允许状态如何收起。多件同时展开时，先规划摆放区域和镜头，不让部件叠住或离开可见范围。


不要根据未知部位自行补造内容。先取得补拍或测量；如果采用估计，在交付说明中写清具体部位及依据。

## 位置、安装层与结构核对

确认位置时统一使用实物正常阅读方向，记录“从正面看／从背面看”、安装在哪一层、距对应边的距离或比例、标签长边朝向及文字方向。标签竖贴不等于旋转任意 90°；背面视图不能直接套用正面的左右坐标。塑封封口还需确认薄膜从哪面延伸、绕过顶部后贴在哪面。用户框选位置应落到部件坐标中，补正反及侧视图核对。


外高、内深、板厚与内容堆叠分别记录，核对闭合剖面、腰封折线与盒盖铰链转动空间。平铺按最大展开占地检查，再压紧间隔；不能只测收纳状态。
