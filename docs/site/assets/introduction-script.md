# DiscAtelier 功能介绍稿

对应视频：3 分钟，18 个章节。此稿供自行录音或后续配音，未嵌入当前视频。时间码用于对照画面，录制时可根据语速调整停顿。

## 00:00—00:09　管理唱片与影碟，查看资料并播放

DiscAtelier 是一款 Windows 影音收藏应用。它可以整理唱片与影碟资料、记录购入信息，并播放收藏。

## 00:09—00:18　浏览、搜索和排序收藏

音乐与影像分区显示，可以按封面或列表浏览，并拖拽排序。搜索范围包括标题、作者、曲目和章节，方便查找收藏。

## 00:18—00:28　分别管理发行版本和每套实体

同一专辑可以保存不同发行版本，同一版本也能记录多套实体。条码、载体和发行资料按版本保存；每套实体分别记录价格、日期、卖家与位置。

## 00:28—00:38　按名称、条码或链接获取资料

用作品名、条码或品番查找 Discogs，粘贴网易云分享链接。影像通过 TMDB 和 Bangumi 查找，没有条目也能手动添加。

## 00:38—00:48　为每张 Disc 关联不同的网易云专辑

一份实体，可以关联多张网易云专辑，按 Disc 分别绑定。简介和曲目各自保留，按实体顺序播放，也能逐曲关联和纠错。

## 00:48—00:57　编辑曲目、封面和制作人员资料

可以编辑曲目、盘内小标题、逐曲演奏与制作人员信息，以及公司资料。也能更换发行版本资料，或使用数据源提供的封面。

## 00:57—01:08　导入三维模型，操作部件与翻页

交互模型可以打开、取放和翻页。三维文件也能直接导入，查看材质与动画。模型指南、AI Skill 和制作入门包，随时下载。

## 01:08—01:19　播放 CD、本地音乐和网易云歌曲

音频 CD、本地音乐和网易云，共用完整播放界面。网易云扫码登录后，按账号权限提供完整音源或试听；成功切换音源后，自动停止原播放。

## 01:19—01:27　跨界面播放，保存最近三个专辑的队列

右下角队列保留最近三个专辑，随时调节音量、切歌和切换循环。离开播放页，音乐仍然继续。

## 01:27—01:38　显示滚动歌词，并支持系统媒体控制

切换歌词，原文和可用译文跟随播放，也能点击跳转。已关联的本地音乐和 CD 同样可用；开启系统媒体控制，用 Windows 面板操作。

## 01:38—01:49　合并影像资料，查看章节与图库

影像作品与实体版本分开。合并两个资料源，简介可以切换。对应剧集汇合图文，动画角色保留头像，海报和剧照放入同一个图库。

## 01:49—01:57　在一套收藏中切换前编和后编

一套实体包含前编和后编时，可以在同一个收藏中分别关联作品资料。首页显示叠放卡片，翻面即可查看另一部分的简介、章节和图片。

## 01:57—02:08　识别光盘资料并播放对应内容

放入光盘，识别载体、关联收藏，查询 CD 曲目资料。播放兼容的 DVD、蓝光菜单和章节，也能关联本地文件，从收藏直接播放。

## 02:08—02:19　通过对话查询收藏、补全资料与控制播放

助手陪你聊音乐、查收藏，准备添加、资料补全、换封面与播放操作。涉及修改收藏，先展示具体变更，等你确认。

## 02:19—02:30　用手机扫描条码、上传购物截图或包装照片

同一无线网络下，手机扫码连接电脑，发送条码、购物截图和包装照片。多张截图一起识别，选择价格、日期等字段，核对后保存。

## 02:30—02:39　记录购入状态、金额和汇率换算

分别记录想购入、在途和已购入状态，也支持同捆购买。保留原币金额，并根据每天更新的汇率显示参考换算与收藏总额。

## 02:39—02:50　管理本地数据、备份与版本更新

收藏存在本地，凭据安全保存。更新前自动备份。查看备份占用，选择删除，恢复前预览。启动检查更新，也允许忽略。

## 02:50—03:00　下载 Windows 版，开始添加收藏

在线资料与 AI 需要配置和网络，音源及光盘播放取决于权限与兼容性。你可以从项目的 GitHub 页面下载安装包，开始添加收藏。
